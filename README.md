# ListTrans · 工程物料清单智能匹配系统

ListTrans 面向洁净工程物料清单，提供 Excel 导入、规范化清洗、物料候选推荐、人工复核、草稿和标准报表导出。

当前版本为 **V0.2.1（已完成统筹终审并按授权部署至本机 Docker；外部正式生产发布仍未授权）**。[V0.2.1 终审与准入](doc/V0.2.1/03_终审与版本准入.md) · [本机门禁验收与部署记录](doc/V0.2.1/rounds/V021_上线强制门禁预验收.md) · [V0.2.0 发布候选边界](doc/V0.2.0/evidence/v020_release_candidate_manifest.md)

## 默认工作流程

1. 登录后上传 `.xlsx` 工程清单。工作台清洗名称、规格、单位、品牌和专业信息，返回通过硬约束过滤的候选；首页首屏展示冻结的首次自动预填比例、四档分布（含 C 档低分预填与安全参数待补双拆）与独立的可导出进度。本地 BGE 可用时提供向量召回，向量不可用时使用关键词 FTS5。
2. 对优先核对（A 档）可打开「集中核对优先项」（默认零勾选、展开原文/目录规格对照后逐行勾选提交），其余行按建议状态逐行选择候选、核对单位与数量后人工确认或拒绝。已验证谱系源行按五元组源行作用域独立确认与失效，修改影响绑定的字段后须重新确认，草稿恢复时会复验权威确认。
3. 导出前服务端复验当前源行权威凭据与实时目录。待确认、已拒绝或确认已失效的行会收到 `422`，按提示处理后重试。物料与人员导入支持其各自模板的 `.xlsx` 和 `.xls`。
4. 管理员先评测规则，再用有效评测凭据确认发布。飞轮规则快照按栈顶顺序回滚。物料更新受目录 revision 与索引切换约束。账号权限、Token 撤销和任务所有者检查持续生效。

## 受控功能与已知边界

- 全部 **11 项实验与 LLM 开关**均保持默认关闭（含 V0.1.8 三项召回实验、V0.1.9 实验评分／重排／自动接受校准、系列重跑、V0.2.0 反馈排序与受控/旧 LLM 开关，以及 V0.2.1 离线 Cross-Encoder 精排实验 `LISTTRANS_V021_M3_RERANKER=off`）。反馈数据尚不足以支持在线自动训练，离线 Cross-Encoder（`BAAI/bge-reranker-base`）实测未达 Dev 提升门槛且超 CPU 预算，维持 OFF 收口；1024 维双塔模型未纳入 V0.2.1。
- 受支持的分段组合 BOM 已做隔离验证。当前 `config/auto_binding_rules.json` 为 `[]`，无生效生产 BOM 规则。受控 LLM 路径仅验证过离线 Mock。
- 冻结全量排名、错误建议及自动接受覆盖仍有已知质量缺口。`PRG-F11`、`ENV-V017-01`、`A-M3-01` 三大上线强制门禁已在本机 Docker 目标范围闭合（仅绑定 `127.0.0.1:18080`）；外部正式生产环境部署前仍须在目标生产机单独完成三门禁验收与发布授权。具体记录见 [V0.2.1 终审与准入](doc/V0.2.1/03_终审与版本准入.md) 与 [本机门禁验收](doc/V0.2.1/rounds/V021_上线强制门禁预验收.md)。

## 技术栈

- 前端：HTML、CSS、原生 JavaScript
- 后端：FastAPI、Uvicorn、Pydantic
- 数据：SQLite、FTS5
- 匹配：结构化特征、关键词检索、向量召回与规则约束
- 文件：pandas、openpyxl

## 快速开始

### 本地启动

使用已核验的 Windows Python 3.12 环境及受控目录副本，从本地读取 `model_offline/bge-small-zh-v1.5`。按[运行手册](deploy_guide.md)准备隔离路径、账号与密钥，再以 Uvicorn 单 Worker 启动本机预验收。单 Worker 用于保持 SQLite 写入、进程内索引和动态规则状态一致。

### Docker

项目保留 `Dockerfile` 和历史 `docker-compose.yml`。Linux 离线运行需使用经验证的候选镜像及受控运行挂载。仓库 Compose 仍引用 V0.1.4 标签并挂载源码，使用边界见[运行手册](deploy_guide.md)。

## 测试与数据安全

测试前按[测试说明](tests/README.md)及 [R01 复验方法](doc/V0.2.0/evidence/m3_r01_reproduce.md)设置仓外临时根、离线护栏及隔离库、配置、向量缓存、上传和输出路径。先通过 `tests/verify_isolation.py` 再运行全量，结束后复核业务资产 SHA256。

## 项目目录

| 目录 | 用途 |
|---|---|
| `app/` | 后端业务代码 |
| `web/` | 前端工作台、登录和管理页面 |
| `config/` | Schema、匹配、清洗和规则配置 |
| `tests/` | 测试与评测工具 |
| `scripts/` | 运维和离线治理脚本 |
| `doc/` | 各版本任务、审核记录及项目文档 |
| `model_offline/` | 本机离线模型文件 |
| `data/`、`logs/` | 运行数据和日志。请谨慎处理 |
