# ListTrans · 工程物料清单智能匹配系统

ListTrans 面向洁净工程物料清单，提供 Excel 导入、清洗提取、关键词与向量候选推荐、人工复核、多物料绑定、进度保存和标准报表导出。

当前对外版本为 **V0.1.4**。本 README 只对应 V0.1.4 已完成并经终审的能力；后续版本仍在内部规划/开发中，不作为当前版本承诺。

## V0.1.4 更新内容

- 完成上传解析、批量匹配和后台重算的异步卸载，降低主事件循环阻塞。
- 完成任务状态并发保护、批量匹配架构治理、评分管道模块化和向量索引原子切换。
- 完成 CORS 白名单、生产模式安全断言、上传大小限制、存储型 XSS 防护和 401 弹窗防抖。
- 支持以工号作为不可变唯一标识，并提供账号自助修改登录名和密码、花名册导入保护及 Token 无缝续期。
- 提供深色/浅色主题切换、启动防闪烁和跨标签主题同步。
- V0.1.4 四个阶段均已完成审核，终审结论为收口通过；遗留的低风险项保留在项目文档中跟踪。

## 技术栈

- 前端：HTML、CSS、原生 JavaScript
- 后端：FastAPI、Uvicorn、Pydantic
- 数据：SQLite、FTS5
- 匹配：结构化特征、关键词检索、向量召回与规则约束
- 文件：pandas、openpyxl

## 快速开始

### 本地启动

1. 准备项目要求的 Python 环境。
2. 安装依赖：

   ```bash
   pip install -r requirements.txt
   ```

3. 按部署环境准备配置文件和必要凭据，不要直接复用历史 README 中的默认账号或密码。
4. Windows 可运行根目录的 `start.bat`；服务默认监听地址以当前配置为准。

生产部署必须保持单 Worker 模式，以避免 SQLite 写锁、进程内缓存和动态规则状态出现跨进程不一致。实际部署前请完成对应环境的配置、权限和回滚检查。

### Docker

项目提供 `Dockerfile` 和 `docker-compose.yml`。使用容器前请检查挂载目录、配置、凭据和数据备份策略；不要把本机业务数据库直接作为测试数据使用。

## 测试与数据安全

测试可能涉及数据库、配置、向量缓存、上传和输出路径。运行测试前请先阅读 [测试说明](tests/README.md)，确认使用隔离环境；不要在未完成隔离核验时直接执行全套历史测试。

## 项目目录

| 目录 | 用途 |
|---|---|
| `app/` | 后端业务代码 |
| `web/` | 前端工作台、登录和管理页面 |
| `config/` | Schema、匹配、清洗和规则配置 |
| `tests/` | 测试与评测工具 |
| `scripts/` | 运维和离线治理脚本 |
| `doc/` | V0.1.4 方案、审核记录及项目文档 |
| `model_offline/` | 本机离线模型文件 |
| `data/`、`logs/` | 运行数据和日志；请谨慎处理 |
