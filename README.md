# 武汉华康世纪洁净科技股份有限公司 · 物料清单智能匹配系统

> **使命：以洁净技术赋能产业升级**

本工具旨在为洁净室工程（涉及暖通、装饰、强电、弱电、给排水、医气等专业）提供高效率、高精度的物料清单智能匹配服务。系统能够将用户上传的原始物料清单自动与企业标准物料数据库进行比对匹配，并生成标准化 Excel 报告。

---

## 🌟 V0.1.0 核心特性 (最新升级)

> **V0.1.0 是"智能工作台人机交互与视觉布局深度重构"的重大体验升级版本**。针对预算员在高频校对、多物料绑定场景下的操作痛点，本版对整个工作台进行了全新的人机工程学重构，实现了空间利用率翻倍、高频按钮秒级触达与大段规格参数舒展呈现。

### V0.1.0 新增能力与布局重构速览

1. **工作台左右分栏 40 : 60 黄金比例优化**
   * **消除多余留白**：左侧清单面板宽度从约 50% 紧凑压缩至 **40%**（`min-width: 320px`），大幅减少表格空白；
   * **核心操作区扩容**：右侧智能匹配面板宽度扩展至 **60%**，为多物料深度比对与候选挑选提供宽阔的横向视野。

2. **右侧上下分栏 3 : 7 与「原始清单数据」3 列并排紧凑化**
   * **3 : 7 垂直黄金分割**：上部高度压缩为 **30%**，下部核心绑定与推荐区扩容为 **70%**；
   * **3 列水平并列排布**：
     * **第 1 列（基础信息）**：单行/紧凑网格展示「设备/材料名称」「工程量」「单位」「甲供分类」；
     * **第 2 列（规格型号/特征描述，空间最大）**：占据约 50% 宽度，充满垂直高度并支持平滑滚动，长文本规格型号无需折叠堆叠；
     * **第 3 列（识别特征维度卡片）**：卡片化展示识别提取的特征维度 Chips，底部集成【重新匹配】与【批量应用】。

3. **「已绑定物料」多卡片并排与 Sticky 固定置顶**
   * **固定置顶（Sticky Top）**：已绑定物料区域固定置顶在下部滚动区域顶部，磨砂高斯模糊背景与阴影保证向下滚动候选卡片或全局搜索时，已绑定项与【确认匹配完成】按钮始终常驻可见；
   * **多列响应式小卡片**：已绑定物料以**一排 2~3 张紧凑小卡片**排布，集成物料名、编码、规格、数量编辑输入框与删除操作。

4. **冗余状态模块移除与全信息候选卡片**
   * **剔除冗余模块**：移除占用过多垂直空间的旧状态卡片，将大量垂直空间归还给推荐候选与全局检索；
   * **候选卡片完整信息呈现**：每张候选卡片完整展示编码、标准名称、完整规格描述、特征匹配 Tags（型号/参数/公差/语义/品牌等）及品牌分类，并在已被绑定的卡片右上角实时渲染「已绑定」绿色徽标。

## 🛠️ 技术栈

* **前端**：HTML5 + Vanilla CSS + Vanilla JavaScript (纯原生，带中央 Token 拦截钩子)
* **后端**：FastAPI + Uvicorn + Pydantic V2 + ThreadPoolExecutor
* **数据库**：双 `SQLite 3` 独立数据库文件（内置 FTS5 全文索引）
  * `app/materials.db`：保存全局企业标准物料明细、LLM 缓存及全文倒排检索。
  * `app/auth.db`：保存用户账号、RBAC 角色权限体系，以及自动暂存草稿和历史命名进度。
* **计算与自然语言处理**：SentenceTransformers (PyTorch-based) + Numpy + FAISS-CPU (可选) + 通义千问 LLM API Client
* **Excel 解析**：openpyxl + pandas

## 🚀 快速开始

### 方式一：本地一键启动 (Windows)

若在 Windows 下直接运行：
1. 确保安装了 Python 3.9 ~ 3.11 版本。
2. 复制配置模板：将根目录下的 `.env.example` 复制为 `.env` 并按需调整密钥和初始管理员密码（大模型接入需配置 `DASHSCOPE_API_KEY`）。
3. 安装依赖项：
   ```bash
   pip install -r requirements.txt
   ```
4. 双击运行根目录下的 [start.bat](file:///Users/tlyer/Project/ListTrans/start.bat)。
5. 系统会自动启动 Web 服务并调用默认浏览器打开本地页面：`http://127.0.0.1:18080`。
6. 使用默认管理员账号进行登录测试：
   * **用户名**：`admin`
   * **密码**：`AdminPassword@2026`

### 方式二：Docker 容器化部署

如果你希望使用 Docker 隔离环境或在 Linux 服务器上部署：
1. 启动容器：
   ```bash
   docker-compose up -d --build
   ```
2. 容器将运行在 `18080` 端口上，访问：`http://localhost:18080`。
