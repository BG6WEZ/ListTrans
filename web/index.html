                             核心算法与高精度决胜机制
                        

                        
    
                            
  • 30 域结构化解析：覆盖风量、功率、口径 (DN/Φ)、材质、耐压、壁厚等核心工程特征。
    • 
                            
  • 多专业清洗优化：针对暖通、医气（脱氧紫铜管/流量）、配管（JDG/SC/壁厚优选）、线缆（阻燃截面 Hard Gate 封顶）定制清洗规则。
    • 
                            
  • 双路混合检索：全文检索 + 离线 Sentence-Transformers 384维语义向量空间比对。
    • 
                            
  • 离线模型加持：系统自带本地离线 NLP 向量引擎，无外网依赖，高并发毫秒级响应。
    • 
                        

                    


                    
                    

                        

                             任务暂存与多版本协同
                        

                        
    
                            
  • 3分钟静默自动保存：工作过程中系统自动暂存草稿，意外刷新或断网重新打开时即刻提示一键恢复。
    • 
                            
  • 多版本命名备份：支持随时点击「暂存进度」自定义阶段名称（如“一阶段复核完成”）。
    • 
                            
  • 历史记录管理：点击「历史记录」可查看所有暂存节点并支持多版本快速切换或清理。
    • 
                            
  • 优雅任务结束：点击「结束任务」可选择安全暂存或清空当前工作区开始下一份清单。
    • 
                        

                    


                    
                    

                        

                             LLM 规则生成与模型调度
                        

                        
    
                            
  • 自然语言规则生成：输入业务描述（如“当清单中出现紫铜管且未标壁厚时自动匹配1.0mm”），AI 自动生成结构化规则。
    • 
                            
  • 规则审核工作台：生成规则需经过人工/主管审核批准后上线生效，杜绝模型幻觉。
    • 
                            
  • LLM Priority Router (管理员)：支持配置多厂家模型节点（通义千问、DeepSeek等），支持优先级队列与超时降级。
