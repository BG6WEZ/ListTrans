### 2.2 数据异构性痛点 (品类漂移现象)
在扫描过程中发现，标准库存在“**分类与名称/规格不完全对齐**”的品类漂移。例如：
* 在 `调节阀` 分类下，混杂了大量的 `静压箱`（如“静压箱 1400\*1200\*1000 mm”）和 `过滤器`；
* 在 `静压箱` 分类下，混杂了 `中效过滤器` 和 `电加热器`。
* **结论**：**系统绝对不能仅依赖“物料分类”来划定属性提取的专业域**。必须结合“物料名称”与“规格文本”的上下文进行联合专业判定，才能保证属性抽取的准确率。

## 三、 `规格/型号` 文本特征与语法结构深度剖析

`规格/型号` 字段平均长度为 **24.04** 个字符，最长为 **288** 个字符。其文本呈现了独特的工业界书写规范。

### 3.1 核心字符及模式覆盖率统计

* **逗号分隔率 (74.91%)**：
  * 有 34,821 行数据使用逗号（`，` 或 `,`）作为物理维度的分隔符。
  * *启示*：数据具备极强的**半结构化天然分割属性**，非常适用于以逗号分段切分后，进行键值对和字典词条正则匹配。
* **乘号匹配率 (41.34%)**：
  * 有 19,215 行数据包含 `*`、`x`、`×`、`X` 字符。
  * *启示*：这几乎囊括了所有设备尺寸（长\*宽\*高）、线缆（芯数\*截面）以及管道壁厚。对乘法算式的正确切分与归一，直接关系到 40% 以上数据的结构化成败。
* **冒号（键值结构）覆盖率 (38.63%)**：
  * 有 17,956 行数据显式包含冒号（`：` 或 `:`），如 `"风量：3140m³/h"`。
  * *启示*：这属于自带结构特征的数据，可以直接进行字段名（Key）和字段值 (Value) 的提取。
* **管径 DN 匹配率 (13.00%)**：
  * 有 6,045 行数据包含 `"DN"`（不区分大小写）字样，代表了给排水和工艺管道的关键直径维度。

### 3.2 常见文本模式分类

通过对 4.6 万行文本的模式归纳，数据的书写有以下四类典型结构：

1. **纯 KV 对链条模式**
   * *示例*：`"风量：3140m³/h，机外余压650pa，镀锌钢板"`
   * *解析难度*：低。通过冒号拆分和正则剥离单位即可轻松获取值。
2. **纯尺寸与材质混合模式**
   * *示例*：`"1550*450*2000 ，镀锌钢板，阻性"`
   * *解析难度*：中。无显式字段名，必须靠位置 and 正则形态匹配（如 `数字*数字*数字` 隐式判定为“尺寸”，`镀锌钢板` 隐式判定为“材质”）。
3. **型号代号 + 复合尺寸模式 (线缆)**
   * *示例*：`"ZB-KVV 7*1.0"` 或 `"WDZ-BYJ 4*6+1*4"`
   * *解析难度*：高。存在型号族的前缀干扰，并且乘法公式中存在 `+` 拼接，需要处理复合电缆情况。
4. **数字 + 物理量隐式混合模式**
   * *示例*：`"电加热功率KW:2"`
   * *解析难度*：中。冒号后面的数字是不带单位的，但字段名中包含单位，需要清洗字段名（如 `电加热功率KW` $\rightarrow$ `功率`）。

## 四、 核心专业域的物理参数规律

为了实现高置信度的打分比对，针对标准库高频分布的专业，其物理参量具有极强的规律性：

### 4.1 暖通专业 (HVAC)
* **主导品类**：通风机、消声器、静压箱、净化过滤设备、空调机组。
* **物理参量提取矩阵**：
  * **风量**：对应单位 `m³/h`、`CMH`、`m3/h`，数值范围一般在 $100 \sim 100,000$ 之间。
  * **余压**：对应单位 `Pa`、`pa`，数值范围在 $10 \sim 2000$ 之间。
  * **功率**：对应单位 `kW`、`kw`、`W`，数值范围一般在 $0.1 \sim 110$ 之间。
  * **物理尺寸**：主要是 `长*宽*高` (3D尺寸)，单位一般是 `mm`。

### 4.2 管道与阀门专业 (Plumbing / Gas / Water)
* **主导品类**：不锈钢管、阀门、汽水集配器、法兰。
* **物理参量提取矩阵**：
  * **管径**：带有 `DN`、`de`、`Ф`、`Φ` 等前缀，数值代表公称直径（如 15, 20, 25, 32, 40, 50, 65, 80, 100, 125, 150, 200, 250, 300 等标准件）。
  * **压力**：带有 `MPa`、`PN`、`PN16`、`pn`，如 `PN16` 对应 $1.6\text{ MPa}$。
  * **壁厚**：管径后面的乘积项，如 `DN32*2.5` 中的 `2.5`。

### 4.3 电气专业 (Strong & Weak Electrical)
* **主导品类**：电气装备用电线电缆、配电柜、开关、控制器。
* **物理参量提取矩阵**：
  * **线缆型号族**：常见有 `YJV`、`KVV`、`BYJ`、`BV`、`BVR`、`RVV` 等。
  * **芯数与面积**：形如 `A*B`。其中 `A` (芯数) 是一般介于 $1 \sim 37$ 的整数，`B` (截面积) 则是标准电缆截面积（如 1.5, 2.5, 4, 6, 10, 16, 25, 35, 50, 70, 95, 120, 150, 185, 240, 300）。

## 五、 现有匹配引擎的结构化阻断机制诊断

结合目前的系统源码与物料库数据，导致匹配置信度不高（大多在 85 分以下，无法触发自动绑定）的代码逻辑层面的“物理硬伤”如下：

### 5.1 逻辑短路造成 Fallback 泛滥
在 [preprocessor.py](file:///Users/tlyer/Project/ListTrans/app/preprocessor.py#L323-L328) 中，分类判定写为：
```python
is_hvac = any(k in category_hint for ...) or (not category_hint and any(...))
```
因为标准物料库的 `category` 字段 100% 存在，故 `not category_hint` 永远为 `False`。导致诸如 `消声器`、`静压箱`、`调节阀` 等分类无法进入 `is_hvac` 专用处理逻辑。这使得 **57.1% 的物料错失了定制的参数解析器**。

### 5.2 字符串污染数值，阻断加分机制
被划归为兜底 `NONE (FALLBACK)` 类的物料，属性是以带单位的原始字符串（如 `"3140m³/h"`）保存的。在匹配引擎 [matcher.py](file:///Users/tlyer/Project/ListTrans/app/matcher.py) 的打分模块中：
1. 属性数值差计算仅接受数值类型 `isinstance(..., (int, float))`。字符串属性无法进行梯级偏差扣分，匹配精准度退化为普通字符串相似度比对。
2. 暖通专业的风量一致加分代码为：
   ```python
   q_vol = float(q_attrs["风量"])
   c_vol = float(c_attrs["风量"])
   ```
   传入 `"3140m³/h"` 会导致 `float()` 直接抛出 `ValueError` 被静默捕获，**彻底丧失核心的加分权重（0.08偏置）**，导致算出的总分极低，自动匹配率降至谷底。

### 5.3 电气箱柜的外观尺寸“污染”线缆属性
在 `is_elec_strong` 中，只要含有乘号，系统便盲目判定为线缆：
```python
cable_matches = re.findall(r'(\d+)\s*[*x×]\s*(\d+(?:\.\d+)?)', text_clean)
```
由于配电柜等设备也属于强电分类，它们的外观尺寸（如 `"布线机柜(600*600*1500)"`）会被错误解析成：
* `芯数` = `600`，`截面积` = `600.0`。
匹配时，当查询端输入真正的电缆时，会因为“芯数不匹配”、“截面积不匹配”触发强电防错机制中的 **-0.40 分毁灭性惩罚**，使匹配列表发生严重错乱。

## 六、 结构化重构治理技术建议

针对上述诊断结论，为在**不改变现有 API 契约（前端零改动）** 的前提下提升匹配率，提出以下三条治理建议：

1. **改进专业判定与多源检索**
   * 修改分类路由，不再以 `not category_hint` 作为前置排他条件。即无论分类信息是否存在，都要对规格/型号正文进行关键词扫描（如正文中含 `排风`、`送风`、`消声器`、`静压箱` 等，均强行归属为 `is_hvac`）。
2. **构建提取后置归一化处理器 (Numeric Normalizer)**
   * 在预处理器末端引入后置处理器。针对 `attrs` 中存储的物理敏感键（如风量、余压、功率、管径等），通过统一的正则处理器（如 `parse_number_or_range`）强行剥离物理单位，并将其转换为标准的 `float` 或是 `int` 数值存储。
3. **实施线缆特征限定与 3D 尺寸过滤**
   * 在提取强电线缆属性前，检测规格文本中是否含有连续两个乘号（如 `A*B*C`），若有则说明是设备体积，跳过线缆解析；
   * 限制仅在品类名称含 `电线`、`电缆`、`导线`，或正文匹配到典型线缆族代号（如 `YJV`/`BYJ`/`KVV`）时才运行芯数解析，切断电气箱柜污染。
