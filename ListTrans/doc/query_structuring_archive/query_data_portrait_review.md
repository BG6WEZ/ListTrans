## 三、主要问题（按重要度排序）

### 问题 1 — 跨专业条目数偏差较大（第四章表格）

| 专业 | 报告值 | 实测值 | 偏差 |
| --- | --- | --- | --- |
| 强电/电气 | 164 | 152 | ✅ 接近 |
| 弱电/自控 | 715 | 724 + 349(特安) | ✅ 接近 |
| 给排水 | **60** | **522** | ❌ 偏离 ~9 倍 |
| 暖通空调 | **2,978** | **7,196** | ❌ 偏差 2.4 倍 |
| 装饰与土建 | **4,747** | **1,140** | ❌ 反向偏差 |
| 医用气体/动力 | 976 | 1,483 | ⚠ |
| 专项材料发包 | 1,717 | 2,737 | ⚠ |

**根因判断**：报告的专业归类口径与文件维度归类不一致。净化项目 / 装饰水电项目内既有装饰又有暖通/水电子项，报告可能按"专业列（章节）"细分做了拆分，而复核脚本按"文件名"归属整包。**该表在"绝对条目数"层面不可直接引用**，但"名称均长、规格均长、规格缺失率"等相对形态指标方向仍成立。

### 问题 2 — 高频品类词 Top 20（第二章 §2）排序失真

实测 Top 20 中出现的 `洁净型无机预涂板 688次`、`同透PVC地板地面 504次`、`楼地面工程 320次`、`墙柱面工程 320次`、`轻钢龙骨 248次`、`CM-插座箱 136次` **未出现在报告 Top 20 里**；而报告中的 `同透 425` / `地板地面 416` / `医用手工单玻岩棉 304` 应是做了**截断/子串合并后**的产物（例如把"同透PVC地板地面"、"同透(PVC)"、"同透"合并计数）。

**影响**：Top20 高频词只能作为"经过归一化后的品类簇"参考，不宜作为原始名称去重结果使用；如后续要做"名称词典/字典树"构建，需要基于**未归一**的实测 Top 榜重新盘点。

### 问题 3 — 有效条目数 12,715 vs 15,173

差 ~2,458 条。方向上是合理的（报告应有更严的表头/小计/合计过滤），但报告未披露过滤规则和被剔除的数量分布，不易复现。

### 问题 4 — 填充率/换行率的分母口径不统一

报告"规格换行比 60.90%"、"含冒号 60.89%"是**相对总条目**的口径；而"平均每条 3~4 行"实际用的是**相对非空**规格的口径。若统一按"非空规格"为分母，换行率 ≈ 99.60%、含冒号 ≈ 99.6% —— 这是一个**更强的**结论，但报告用整体分母把这一亮点稀释了。

### 问题 5 — 名称"序号前缀污染 0.48%"高估

实测严格意义上的序号前缀（`1.` / `①`）只 0.01%。报告 0.48% 可能把 `1.1` / `1.1.1` 这种小节号识别为清单行，或者把"合计 / 小计"未剔除干净。这一项影响不大，但提示"数据清洗率"报告值可能过于乐观。

## 四、被证实为**正确**的核心洞察

- ✅ **名称短、规格长、规格 Key-Value 结构强** — 整体形态判断完全正确。
- ✅ 规格列 Key 分布（`工作内容 / 规格 / 名称 / 材质 / 型号 / 安装方式 / 连接形式 …`）**数据几乎精确一致**（差异 <1%）。这是最关键、后续解析器要用的部分，可放心使用。
- ✅ 第五章的四条**转换/匹配启示**全部站得住：
  1. 匹配重心必须放在"规格解析"上 — 强电/弱电/给排水名称均长 3.7–4.9 字，本次复核证实。
  2. `序号 + Key + : + Value + \n` 结构在**非空规格**中覆盖率高达 **99.6%**（比报告的 60% 更强）— 更利好后续正则/规则抽取。
  3. 需要"名称反向提取规格"能力 — 尤其 PVC/橡胶专项发包，实测规格几乎全空（缺失率 >99%）。
  4. 需清洗 `工作内容` / 重复的 `名称` 噪音 — 属性 Key 榜实测证实。

## 五、修订建议（Actionable）

1. **明确"有效条目"过滤规则** — 说明剔除合计、章节、空行、图纸说明等的规则，并披露剔除条数分布，以便复现 `12,715` 这个数字。
2. **跨专业表补充归类依据** — 说明是按"文件"还是按"sheet 名"还是按"专业列关键字"归类，或改用 sheet 级归类重跑一遍数据。
3. **Top 20 高频品类词双榜发布** — 区分"**原始名称频次**"与"**归一化后品类簇频次**"两张榜。
4. **§3.1 / §3.3 统计口径统一** — "规格含冒号/含换行"应同时给出"相对全部 / 相对非空"两种口径。后者（≈99.6%）才是解析器真正关心的覆盖率，也是本报告最大的隐藏亮点。
5. **§2.3 "序号前缀污染"数字下调** — 复核后应下调到 <0.05%（除非把"章节小节号"也算进去，需明确说明）。
6. **附上统计脚本** — 建议随报告提交 `audit_query_portrait.py`、`audit_by_discipline.py` 或等价脚本，让所有数字可被审计与复现。
