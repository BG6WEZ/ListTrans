# 华康洁净物料清单智能匹配工具 (Huakang Clean Material List Matching Tool)

本工具旨在为洁净室工程（涉及暖通、装饰、强电、弱电、给排水、医气等专业）提供高效率、高精度的物料清单智能匹配服务。系统能够将用户上传的原始物料清单自动与企业标准物料数据库进行比对匹配，并生成标准化 Excel 报告。

---

## 🌟 V0.0.9 核心特性 (最新升级)

> **V0.0.9 是"系统安全性、稳定性闭环，配合大纲标题自动过滤与匹配性能提速"的重大升级版本**。在原有 30 域特征打分与全员组织权限体系基础之上，本版彻底闭环了全部独立安全与稳定性核验指标（安全密钥加固、前端30s防挂起遮罩熔断、并发死锁消除），并重磅推出了根据待处理清单行数自动线性扩容的“后端动态超时护栏”以及“大纲章节行智能剔除算法”，实现了高压并发与超大清单处理下的系统自愈与流畅体验。

### V0.0.9 新增能力速览

1. **安全性加固与 JWT 强密钥防自签**
   * **剔除静态密钥**：彻底清除代码中任何硬编码的 JWT 默认静态密钥，强制读取环境变量。若未读取到，则于运行时在内存中自动生成 256 位高强度安全随机密钥，杜绝离线自签 Token 提权风险（闭环 P1-3）。
   * **API 鉴权与路径防越权**：对全部核心管理接口（如系统数据重置）进行严格角色收敛与鉴权拦截，并加入文件上传防路径穿越安全过滤。

2. **Excel 大纲标题与章节行智能剔除过滤**
   * **大纲行智能清洗**：针对 Excel 清单中大量的章节大纲标题（如 `"一、管道"`、`"呼叫系统"`），开发了基于正则与中文分部术语的大纲标题识别器。
   * **剔除 35+ 行冗余数据**：直接剔除此类无规格、无单位的纯文本结构行，使有效处理行数精简 5% 以上，防止其进入打分阶段产生噪点匹配，提高清洗精度并减小计算负荷。

3. **动态超时熔断护栏与 GIL 打分速度优化**
   * **动态线性超时扩容**：后台上传匹配任务引入了动态安全超时算法（`matching_timeout = max(120.0, len(raw_rows) * 1.5)`），防止数千行的超庞大清单被一刀切超时熔断，在保证防挂起安全阈值的同时，大幅拓展大清单的生产可用度（闭环 P0-4）。
   * **3.6 倍速度优化**：通过优化多路检索召回限额（如 FTS 候选从 1000 降至 150，语义向量候选从 200 降至 50），直接将匹配提速至 15.4 行/秒，800行以上项目清洗仅需 30~35 秒完成。

4. **UI 加载遮罩 30s 兜底自动释放 (P0-3)**
   * **遮罩防无限锁死**：前端 loading 提示加入 30 秒兜底解锁及 60 秒硬性封顶限制，确保任何网络延迟或后端罕见异常下前端都不会发生无限转圈卡死。

5. **并发死锁消除与全量测试**
   * **死锁防护**：将全局统计追踪器（`RuleHitStatsTracker`）互斥锁升级为 `threading.RLock`（可重入锁），消除规则审计与上传并发时的潜在死锁（闭环 P0-1）。
   * **全量回归测试**：61项回归测试 100% 通过（耗时仅 12.8s）。

## 🛠️ 技术栈

* **前端**：HTML5 + Vanilla CSS + Vanilla JavaScript (纯原生，带中央 Token 拦截钩子)
* **后端**：FastAPI + Uvicorn + Pydantic V2 + ThreadPoolExecutor
* **数据库**：双 `SQLite 3` 独立数据库文件（内置 FTS5 全文索引）
  * `app/materials.db`：保存全局企业标准物料明细、LLM 缓存及全文倒排检索。
  * `app/auth.db`：保存用户账号、RBAC 角色权限体系，以及自动暂存草稿和历史命名进度。
* **计算与自然语言处理**：SentenceTransformers (PyTorch-based) + Numpy + FAISS-CPU (可选) + 通义千问 LLM API Client
* **Excel 解析**：openpyxl + pandas

## 🚀 快速开始

### 方式一：本地一键启动 (Windows)

若在 Windows 下直接运行：
1. 确保安装了 Python 3.9 ~ 3.11 版本。
2. 复制配置模板：将根目录下的 `.env.example` 复制为 `.env` 并按需调整密钥和初始管理员密码（大模型接入需配置 `DASHSCOPE_API_KEY`）。
3. 安装依赖项：
   ```bash
   pip install -r requirements.txt
   ```
4. 双击运行根目录下的 [start.bat](file:///Users/tlyer/Project/ListTrans/start.bat)。
5. 系统会自动启动 Web 服务并调用默认浏览器打开本地页面：`http://127.0.0.1:18080`。
6. 使用默认管理员账号进行登录测试：
   * **用户名**：`admin`
   * **密码**：`AdminPassword@2026`

### 方式二：Docker 容器化部署

如果你希望使用 Docker 隔离环境或在 Linux 服务器上部署：
1. 启动容器：
   ```bash
   docker-compose up -d --build
   ```
2. 容器将运行在 `18080` 端口上，访问：`http://localhost:18080`。
