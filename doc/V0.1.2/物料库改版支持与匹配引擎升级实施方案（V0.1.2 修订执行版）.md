# 物料库改版支持与匹配引擎升级实施方案（V0.1.2 修订执行版）

## 一、背景与建设目标

为了解决物料库历史积累导致的“一尺寸一编码、颗粒度过细、冗余物料庞大、多业态描述不通用”等问题，业务侧推进了《物料编码瘦身方案》。在 `20260817（部分改版）.xlsx` 物料库中，物料形态发生重大调整（包括禁用标记迁移、半周长级距、三维容差、消声器双区间、设备参数精简等）。

本实施方案基于 [material_library_cleaning_and_matching_solution.md](file:///c:/Users/wangd/project/ListTrans/doc/V0.1.2/material_library_cleaning_and_matching_solution.md) 与 [material_library_revamp_analysis_report.md](file:///c:/Users/wangd/project/ListTrans/doc/V0.1.2/material_library_revamp_analysis_report.md)，并吸纳 [material_library_revamp_review_report.md](file:///c:/Users/wangd/project/ListTrans/doc/V0.1.2/material_library_revamp_review_report.md) 的独立评审纠偏结论，制定客观、严密、可落地的工程实施方案。

## 二、关键问题客观定性与根因纠正

在实施前，必须统一以下关键认知与技术定性：

### 2.1 禁用物料拦截机制与标记形态迁移
- **客观事实**：改版后物料库总行数 **50,375 行**，其中禁用物料达 **10,955 行（21.75%）**。
  - `code` 列命中：**673 行**（历史形态，如 `[WL1000386422（禁用）]`）；
  - `name` 列命中：**10,281 行**（改版新增形态，如 `UPVC管管件（禁用260930）`）；
  - `spec` 列命中：**1 行**。
- **原代码缺陷定性**：原系统仅针对 `code` 列进行过滤（`df_cleaned["code"]`），导致新增标注在 `name` 列的 **10,281 条老旧淘汰物料全部穿透** 进入数据库及向量索引。
- **规则修正**：收紧为 `re.compile(r'禁用|停用|无效')` 全字段扫描；严禁使用裸数字正则（如 `26\d{4}`）以避免未来图号误删，剔除 `废弃` 关键词以保护在用物料（如 `[3.61.19.0001] PP废液收集车`），保证入库标准有效活跃物料精准为 **39,420 行**。

### 2.2 “全候选满分 100 分”真实根因追踪与前置修复
- **实测复现**：输入 `多叶调节风阀 630*400 手动 镀锌钢板` 时，库内 8 个不同半周长区间的候选物料同获 **100.00 分**。
- **真实根因链条**：
  1. `extract_device_name` 抽取时未剥离 `半周长：` 等标签词，输出残留污染名称 `多叶调节风阀 半周长：~`；
  2. `route_domain` 受到污染名称干扰，且未优先信任 `category`（`多叶调节风阀`），将该风阀**误判为 `valve_water`（水阀）**；
  3. `valve_water` 的 `must_keys` 为 `['阀型', '管径', '材质', '连接方式']`，根本不包含 `尺寸`，导致风阀尺寸门禁被完全绕过；
  4. 材质匹配且名称相似度高，叠加加分规则后全候选截断至 100 分。
- **关键工程结论**：若仅在 `damper` 领域中补充区间打分，由于路由已走入 `valve_water`，新打分代码将永远不被执行！**必须首先完成抽取层净化与领域路由前置修复**。
- **附带缺陷清理**：修复 `extract_decoration_params` / `extract_params` 中因正则未严格限定而将 `1~500mm` 误提取为 `厚度=500.0` 的脏属性缺陷。

### 2.3 存量形态与改版演进关系
- 半周长（0811 版 74 条 $\rightarrow$ 0817 版 340 条）、三维容差（32 条 $\rightarrow$ 279 条）、参数区间（3,307 条 $\rightarrow$ 5,812 条）在原物料库已存在存量，改版将其规范化并大幅扩展。本次改造本质是**彻底解决系统长期存在的存量抽取与打分缺陷**。

### 4.1 模块一：数据治理与全字段精准禁用拦截（[app/db_manager.py](file:///c:/Users/wangd/project/ListTrans/app/db_manager.py)）

1. **精准全字段联合扫描**：
   ```python
   DISABLE_KEYWORD_PATTERN = re.compile(r'禁用|停用|无效')

   def check_row_disabled(row: pd.Series) -> Tuple[bool, str]:
       fields = [
           ("code", str(row.get("code", ""))),
           ("name", str(row.get("name", ""))),
           ("category", str(row.get("category", ""))),
           ("specification", str(row.get("specification", ""))),
           ("description", str(row.get("description", "")))
       ]
       for field_name, val in fields:
           val_clean = val.strip()
           if DISABLE_KEYWORD_PATTERN.search(val_clean):
               return True, f"字段[{field_name}]命中禁用标记: {val_clean}"
       return False, ""
   ```
2. **审计输出与元数据**：
   - 导入时将 10,955 条禁用记录输出至 `data/audit_disabled_materials_YYYYMMDD.csv`。
   - 更新数据库元数据：`total_rows=50375`, `imported_rows=39420`, `disabled_rows=10955`。
3. **重复编码（37行）治理**：
   - 遇到相同 `code` 时，按有效字段完整度优先保留，记录去重告警日志。

### 4.3 模块三：几何特征抽取与复合双区间解析引擎（[app/domain_extractors.py](file:///c:/Users/wangd/project/ListTrans/app/domain_extractors.py)）

1. **清单端衍生几何特征**：
   矩形尺寸 $L \times W$（如 `630*400`）自动计算：
   $$\text{半周长} = L + W = 1030.0$$
2. **物料端全角冒号半周长与消声器双区间提取**：
   ```python
   def extract_half_perimeter_and_length(text: str) -> Dict[str, Any]:
       res = {}
       # 兼容全角冒号 ：与半角冒号 :
       hp_m = re.search(r'半周长\s*[：:]?\s*(\d+)\s*[~～\-—至到]\s*(\d+)\s*(?:mm|m)?', text)
       if hp_m:
           res["半周长_min"] = float(hp_m.group(1))
           res["半周长_max"] = float(hp_m.group(2))
           res["半周长"] = (res["半周长_min"] + res["半周长_max"]) / 2.0
       
       # 提取消声器第二维：长度区间
       len_m = re.search(r'长度\s*[：:]?\s*(\d+)\s*[~～\-—至到]\s*(\d+)\s*(?:mm|m)?', text)
       if len_m:
           res["长度_min"] = float(len_m.group(1))
           res["长度_max"] = float(len_m.group(2))
           res["长"] = (res["长度_min"] + res["长度_max"]) / 2.0
       return res
   ```
3. **三维容差区间解析器**：
   解析 `（1500±150）*（1500±150）*（900±150）mm`，提取长、宽、高基准值及上下界容差。
4. **医用物料双写别名保护**（[app/normalizer.py](file:///c:/Users/wangd/project/ListTrans/app/normalizer.py)）：
   保留库内 1,965 条有效在用“医用”物料的原始名称，生成归一化别名 `normalized_alias` 辅助召回，不做破坏性全局替换。

### 4.5 模块五：级距打分引擎与业务单位规范（[app/matcher.py](file:///c:/Users/wangd/project/ListTrans/app/matcher.py)）

1. **级距宽度归一化打分算法**：
   ```python
   def score_point_vs_interval(point_val: float, min_val: float, max_val: float) -> float:
       if min_val <= point_val <= max_val:
           return 1.0
       width = max(max_val - min_val, 1.0)
       dist = (min_val - point_val) if point_val < min_val else (point_val - max_val)
       return max(0.0, 1.0 - dist / width)
   ```
2. **级距空档（跳段）最近邻兜底**：
   当输入落入库内级距空档导致所有候选得分 `< 0.3` 时，回退选取物理距离最近的区间候选，并附加标记 `"级距空档，选取最近邻候选，需人工复核"`。
3. **消声器双区间加权打分**：
   $$\text{Score}_{\text{dim}} = 0.6 \times \text{Score}_{\text{半周长}} + 0.4 \times \text{Score}_{\text{长度}}$$
4. **业务单位规范修正**：
   - 严格落实业务《瘦身方案》第 3 条原则（“门不能按㎡”），**删除 `("樘", "㎡")` 映射**；门类按材质与开启方式匹配。
   - 限定 `("项", "批")`、`("项", "套")` 仅在管件辅材类生效。
5. **Schema 必填项优化**（[config/domain_schema.json](file:///c:/Users/wangd/project/ListTrans/config/domain_schema.json)）：
   `fan` 领域将 `机外余压`、`静压` 从 `must` 降级为 `should`。
