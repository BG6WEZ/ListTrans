# 华康洁净物料匹配系统 · V0.1.1 版本升级与回滚操作指南

> **版本号**：V0.1.1  
> **核心升级内容**：向量匹配模型全面升级为 **BGE-small-zh-v1.5**（512 维中文增强模型），实现更高精度的物料语义召回与匹配。  
> **发布日期**：2026-08-17

---

## 一、升级背景与核心改进

在工程物料（洁净室、暖通风机、配电箱柜、阀门管道等）场景下，原始的通用句向量模型对中文专有名词、缩写和规格型号的语义区分度有限。
**V0.1.1** 将底层语义向量模型由 `paraphrase-multilingual-MiniLM-L12-v2` 升级为北京智源研究院的 **`BGE-small-zh-v1.5`**。

### 1.1 关键改进点
1. **模型能力提升**：
   - 专为中文检索与语义相似度优化，词表针对中文语境强化。
   - 向量维度从 384 维提升至 **512 维**，具备更丰富的高维工程语义表征能力。
2. **全流程离线适配**：
   - 预置离线模型至 `model_offline/bge-small-zh-v1.5/`，严防内网断网卡顿（`HF_HUB_OFFLINE=1` 保护）。
3. **缓存元数据自愈机制**：
   - 在 `app/vector_cache/cache_metadata.json` 中记录向量模型名称与维度。
   - 系统启动时自动校验模型与缓存维度一致性，杜绝维度不匹配导致的服务异常。
4. **灵活可配置与一键回退**：
   - 新增 `config/model_config.json`，可通过修改配置文件或环境变量 `EMBEDDING_MODEL` 实现秒级无缝切换与回滚。

## 二、配置与一键回退 (Rollback) 操作说明

系统完全保留了原旧版模型文件（`model_offline/paraphrase-multilingual-MiniLM-L12-v2`），如遇特殊情况需要回滚至旧版模型，只需以下简单步骤：

### 2.1 方式一：修改配置文件回退（推荐）

打开项目配置文件 [config/model_config.json](file:///c:/Users/wangd/project/ListTrans/config/model_config.json)，将 `embedding_model` 改为 `paraphrase-multilingual-MiniLM-L12-v2`：

```json
{
  "version": "0.1.1",
  "embedding_model": "paraphrase-multilingual-MiniLM-L12-v2",
  "available_models": {
    "bge-small-zh-v1.5": {
      "dimension": 512,
      "description": "BAAI BGE Small Chinese v1.5 (优选中文检索向量模型，512维)",
      "offline_dir": "bge-small-zh-v1.5"
    },
    "paraphrase-multilingual-MiniLM-L12-v2": {
      "dimension": 384,
      "description": "MiniLM L12 v2 (通用多语言句向量模型，384维，回滚备用)",
      "offline_dir": "paraphrase-multilingual-MiniLM-L12-v2"
    }
  }
}
```

### 2.2 方式二：环境变量动态覆盖

在启动前设置环境变量 `EMBEDDING_MODEL`：

```bash
# Windows PowerShell
$env:EMBEDDING_MODEL="paraphrase-multilingual-MiniLM-L12-v2"
python -m uvicorn app.server:app --host 0.0.0.0 --port 18080

# 或 Linux / Docker
export EMBEDDING_MODEL=paraphrase-multilingual-MiniLM-L12-v2
```

### 2.3 重建向量缓存

切换模型后，系统在首次启动或调用 `/api/upload` / `check_db_timestamp_and_build` 时会自动识别维度变动并重新计算向量，或在前端【系统参数配置】/【全品物料明细库】中点击“重建向量索引”。

| **端到端集成测试** | 100% (11/11) | **100% (11/11)** | 全部通过 |
