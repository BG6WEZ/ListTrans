# 华康洁净物料清单匹配系统数据清洗与全量参数提取规则手册 (V2.0)

本手册将匹配系统内部针对 **33个标准物料域 (Domains)** 以及关联的 **385个底层物料大类 (Categories)** 的数据清洗与参数提取规则进行了全量梳理，并整理为直观、完备的表格形式，以保障数据清洗的质量，供各专业组专家进行深度审核。

---

## 一、 通用清洗与数据归一化处理表

在进行具体参数提取前，系统必须对 **清单端 (Query)** 和 **物料库端 (DB)** 的原始文本进行统一的数据清洗，确保数据格式完全同频：

| 清洗步骤 | 处理对象 | 具体执行逻辑与业务定义 | 输入示例 | 清洗后输出 |
| :--- | :--- | :--- | :--- | :--- |
| **符号全角转半角** | 双端文本 | 将中文全角括号、逗号、冒号等统一转换为英文半角符号，统一全半角空格。 | `（30KVA），Pe＝10ｋＷ` | `(30KVA),Pe=10kW` |
| **乘号与空格归一化** | 尺寸/截面 | 消除多余空格，将非标准乘号（如 `×`、`x`、`X`）统一转为 `*`。 | `3  x  2.5` 或 `3 × 2.5` | `3*2.5` |
| **施工/工作内容噪音过滤** | 清单规格 (Query) | 自动按行拆分文本，识别并直接剥离与物料本体无关的现场施工及安装描述。 | `1. 材质: 304<br>2. 厂家负责安装及调试` | `1. 材质: 304` |
| **字段错位智能智能纠偏** | 清单名称 (Query) | 识别名称中的规格特征（如 `DN50`），自动将其切分移入规格字段，净化名称。 | 名称: `焊接钢管 DN100`<br>规格: `空` | 名称: `焊接钢管`<br>规格: `DN100` |
| **文本归一化同义词映射** | 双端文本 | 建立常用近义词库，启动前对特定关键字进行标准替换，消除拼写和标准偏差。 | `SUS304` 或 `不锈钢304` | `304` |
