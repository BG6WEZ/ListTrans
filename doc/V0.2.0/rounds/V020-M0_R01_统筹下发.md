| 条目 | 必做与验收 |
|---|---|
| 反馈标签复核与数据充足性判定 | 建立可复现的反馈样本提取、标签一致性复核与人工分歧追溯流程（兼容飞轮 SQLite 表结构，在仓外隔离测试库验证）。针对当前本地真实生产反馈为 0 的客观事实，如实输出**数据充足性门禁判定**（明确区分“真实生产反馈不足/不启用在线自动训练”与“离线基准数据实验”），不得把收集反馈次数或合成样本包装为线上准确率收益。 |
| 同名不同规格 Hard Negatives 与防泄漏划分 | 基于冻结基准的 **Train 842**（及仓外隔离合成反馈夹具）构建**同名不同规格 hard negatives**（重点覆盖同名称不同 DN/外径、材质 304 vs 316L、型号尾缀、防爆/提升泵否定及装饰/强电高竞争项），明确按**项目/时间维度留出**的防泄漏划分协议与校验断言（保证训练、验证、留出之间无项目/来源清单与时间泄漏；**绝对禁止读取或使用 Test 160 参与任何样本构造、特征选择或调参**）。 |
| 受控排序器 / 特征权重实验与选型裁决 | 在冻结物料库、冻结索引与离线 `bge-small-zh-v1.5` 条件下，严格在 **Train 842 训练、Dev 218 比较**，评估基于硬负例与结构化差异特征的**轻量受控排序器/特征权重方案**（不依赖新外部模型权重、不引入 Cross-Encoder 或 1024 维模型，这两项按用户指示延后至 V0.2.1）。必须同条件对照默认 OFF 基线，报告关键词与离线 BGE 双模式的 Recall@100/200、Hit@1/3、MRR@10/全排序、分域差值、可回答与负例错误建议、负例显式拒绝、错误自动绑定（硬上限 0）及单条/50 行上传 P50/P95 与峰值工作集。 |
