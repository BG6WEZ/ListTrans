# V020-M1 R01 支持范围与规则迁移

R01 支持暖通专业的 **304 薄壁不锈钢管分段组合**。原始项目名称为 `304薄壁不锈钢管分段组合`，原始品类为 `不锈钢管`。展开使用原始文本，规格必须明确 DN、外径 D（mm）和 304。管理员建规则时使用下表的规范规格。匹配支持英文大小写、SUS304 和全角输入归一。未知条件或表外规格转人工复核。

| 规范规格 | 非保温段 | 保温段 | 壁厚 |
|---|---|---|---:|
| `DN25 D25.4 304` | `2.17.05.0628` | `2.17.05.0479` | 1.0 mm |
| `DN50 D50.8 304` | `2.17.05.0631` | `2.17.05.0482` | 1.2 mm |

两段的实时物料单位、名称、品类、DN、外径、壁厚和牌号应与目录证据一致。组合用于明确声明同规格管路中两段长度的工程清单。两个子项的原始长度份额由管理员按工程依据独立声明，各自大于 0 且合计为 1。仓库规则文件当前为空，两段没有预置份额。[冻结目录只读核对](m1_r01_catalog_evidence.json)

规则中的 `bound_materials[].qty_ratio` 表示原始长度份额。每个子项先按 `UNIT_SYNONYMS` 归一可靠单位，再用 `get_unit_multiplier` 查已有换算表。匹配和导出中的 `qty_ratio` 等于长度份额乘单位倍率，工程量等于原始工程量乘该比例。原行可用 m、km、cm、mm 及其登记同义词。测试示例的 2 千米按 60% 和 40% 分段，导出 1,200 m 与 800 m，输出比例分别为 600 和 400。面积、缺单位和未知单位进入复核。

确认、恢复和导出重算完整集合，逐项校验用量、比例、当前目标单位和硬约束。少项、多项、重复、错码和任一子项物料失效均不能导出。草稿可以保留人工录入的有限正数量候选，行状态保留待复核或拒绝。重算、编辑或历史确认与当前规则不一致时须再确认。XLSX 的原项和两条材料费保留独立行，材料费工程量单元格批注保留各自比例。

## 管理员评测、历史规则与回退

规则继续从 `/api/binding/rules/eval` 进入，`/api/binding/rules/confirm` 检查同一负载、目录、配置、算法和评测资产版本对应的凭据。对于上述族，明确专业、规范规格、两段编码、目标单位和长度份额后，服务端生成 BOM v1 条件元数据，并纳入评测摘要。发布前评测要求至少一条独立 `1toN` 样本，带完整预期编码、子项单位、工程量和最终绑定比例（`bom_expected`），同时保留已有保护集门槛。无对应评测资产时不能取得有效凭据。本轮用隔离夹具验证，实际规则文件没有写入。

旧规则继续由原列表读取：

- 上述族的未版本化旧条目以待复核处理，历史规则文件保留。迁移时由管理员补齐实际工程依据，走完整评测和确认流程。成功确认后，按原名称、专业和规范规格键原子替换。绕开评测直接确认、借现有评测凭据更换份额或直接沿用旧条目均无效。
- 通用旧名称-only 规则仍可作历史人工推荐。只有规格受约束、通过完整逐项校验的旧多绑定可以自动接受。旧多绑定的规格 token 要求完整边界，避免 `DN15` 命中 `DN150`。单绑定及旧规则已支持的数量行为通过关联回归验证。
- 迁移回退使用迁移前规则文件快照与项目现有原子保存/补偿路径。撤回 v1 规则后，其先前组合需重新复核。代码回退在仓外副本演练，使用本轮补丁恢复已修改文件字节，并清理新增实现和测试。若未来真实环境已有 v1 规则，须先用受控配置回退到相应迁移前快照，再考虑回退程序版本。
