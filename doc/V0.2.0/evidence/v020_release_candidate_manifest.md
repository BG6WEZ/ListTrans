## 验收与支持限制

- 默认配置的全量串行回归 497 项通过，OFF 三规则门禁通过，目录/索引及规则恢复在仓外隔离副本通过。BOM 实际评测与确认仅使用隔离夹具。[总复核矩阵](m3_r01_review_matrix.md)
- 本机 Docker CLI 存在，两个本地守护进程端点均不可达。当前 Linux 容器断网构建、镜像层与脱敏启动待验证，关联 `ENV-V017-01`。历史镜像验收证据按其当时基线使用。[本机探针](m3_r01_followup/m3_r01_inventory.json)
- `PRG-F11` 保持开放，首次真实部署前由授权运维完成历史凭据轮换与脱敏核验。
- 全量排名、错误建议和接受覆盖仍有签认质量缺口。性能抽样限 Train/Dev，Test 160 保持留出。Cross-Encoder 与 1024 维向量评估按裁决延后至 V0.2.1 再议。[V0.1.7 质量与性能预算](../../V0.1.7/evidence/指标目标与性能预算_统筹签认.md) · [总复核矩阵](m3_r01_review_matrix.md)

### 性能抽复验

本机 Windows Python 3.12.10，每模式 200 次单条和 20 次 50 行上传。独立进程、冻结业务快照、10 项开关全 OFF。每模式实际出站尝试与 LLM 传输调用均为 0。BGE 使用本地 512 维模型及 26,863 条 NumPy 索引。

| 模式 | 单条 P50/P95 ms | 50 行 P50/P95 s | 峰值工作集 MiB |
|---|---:|---:|---:|
| 关键词 | **36.366 / 384.659**（上限 30 / 300） | 1.532 / 7.948（上限 1.75 / 10.0） | 599.23（上限 768） |
| BGE | **85.836 / 400.685**（上限 90 / 375） | 5.198 / 11.170（上限 6.0 / 12.5） | 1,201.79（上限 2,048） |

首测的关键词单条 P50/P95 和 BGE 单条 P95 超限，50 行上传和峰值工作集在预算内。独立进程用相同输入和预热重测，关键词为 **35.081 / 373.905 ms**，BGE 为 **87.922 / 480.869 ms**，超限项一致。`V020-M3-PERF-01` 留待独立审核及统筹裁决。此抽样使用 Train/Dev 子集和五条预热，V0.1.7 签认跑过全量排名后执行 HTTP 测量。跨轮样本与预热存在差异，超限原因待核对，原预算保留。[关键词首测](m3_r01_followup/m3_r01_perf_keyword.json) · [BGE 首测](m3_r01_followup/m3_r01_perf_vector.json) · [关键词复测](m3_r01_repeat/m3_r01_perf_keyword.json) · [BGE 复测](m3_r01_repeat/m3_r01_perf_vector.json)
