## 范围与验收

| 条目 | 必做与验收 |
|---|---|
| 排序分与接受置信度分离 | 明确分离 ranking score 与接受/拒绝置信度（`is_exact` 仅保留历史算法提示语义，不得直接升级为可导出状态）。构建独立、可解释的置信度与决策校准模块，输出校准置信度、决策状态（自动接受 / 推荐待复核 / 待补参或显式拒绝）及逐项阻断/触发原因。 |
| 联合判定与 R-M3-01 闭合 | 自动接受必须联合核验：① 关键字段完整性与 unknown 检查——专业、型号/核心规格、材质牌号、DN/外径、单位倍率、防爆/提升泵三态等关键字段存在 unknown 或关键安全约束缺失时，**一律禁止自动接受**，显式闭合 **R-M3-01**（GT-0674/0677/0678 防爆 unknown 必须保持不可自动接受与导出 422 拦截，并输出清晰的待复核/待补参原因）；② 无硬冲突且无不可逆降权封顶（`hard_blocked=False`、`max_score==1.0` 且通过 `evaluate_hard_conflicts` 新鲜复核）；③ Top1/Top2 间隔与已确认等价编码消歧——Top2 若属冻结等价编码集合则不误判为歧义竞争，否则间隔不足时禁止自动接受；④ 无答案/弱证据/高冲突行明确判为显式拒绝或待补参（不输出错误预绑定），降低错误建议绑定并提高负例显式拒绝。 |
| 权威导出与状态契约安全 | 严守 V015-M2/M3 与 V016-M2 服务端权威契约：**客户端自报 `decision_status="auto_accepted"`、`is_exact` 或置信度字段一律不被采信**。若校准策略在服务端判定某行为 `auto_accepted`，`/api/export` 与草稿恢复链路必须执行同源实时新鲜校验（当前有效编码 + `evaluate_hard_conflicts` + 服务端校准判定/凭据复核），且保持人工拒绝优先、人工确认双指纹绑定与非 1 倍率单位换算权威证据零回退。不得通过降低物理硬约束门禁换取自动接受覆盖率。 |
| 精确率—覆盖率与误差目标 | 依据 [V0.1.7 签认指标与预算](../../V0.1.7/evidence/指标目标与性能预算_统筹签认.md)：① **错误自动绑定（可判定核心）上限 0、关键冲突误自动接受上限 0**；② 一旦出现可判定自动接受，冻结样本精确率须为 **100%**，同时必须报告精确率—覆盖率曲线、样本量分母及 **Wilson 95% 置信区间**；**样本量不足时严禁宣称达到 99% 等高精度**；③ 负例显式拒绝不低于同片基线（关键词 26/115、BGE 23/115），可回答与负例错误建议绑定不高于同片基线；④ 明确区分“可回答精确命中自动接受”“等价编码自动接受”“待复核推荐”“显式拒绝/待补参”四类计数。 |
| 默认关闭开关与性能预算 | 校准策略置于独立默认关闭开关（如 `LISTTRANS_V019_M2_CALIBRATION=off`）之后；非法配置回退 `off`。关闭时 100% 逐条复现 M1/M0 默认路径（旧评分 + 重排 OFF + 三召回 OFF）。以 `legacy` 排序为主对照完成关键词与离线 BGE 双模式评测（如补充叠加 M0/M1 实验档的组合诊断须单列不混算）。严格遵守 V0.1.7 签认单条/50 行上传 P50/P95 与峰值工作集上限；若超预算或出现任何误自动绑定则保持关闭并如实披露。 |

前端复核界面交互改造、状态视觉呈现与端到端人工复核耗时测量归 **V019-M3**，本包不扩做前端交互重构（仅保持既有响应字段向后兼容）。GT-0003/0155 维持原标签与计分。
