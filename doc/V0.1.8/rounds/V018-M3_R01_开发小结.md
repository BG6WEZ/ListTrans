- **关键根因解释**：

  2. **未召回 / 截断 / 排序未命中分布（`B0_VEC_OFF` Train+Dev 651 条）**：未召回 **78 条**（强电 31、医用气体 18、弱电 16、装饰 8、自控 3、暖通 2）、超过 200 截断 **0 条**、已召回但硬约束拦截 **80 条**、已召回且未拦截但排序 >10 位 **147 条**（强电 41、医用气体 32、暖通 30、弱电 23、装饰 21）。扩大召回类实验（`M1`/`C2`）可将未召回降至 41～44 条，但在 V0.1.8 冻结排序权重下，新增干扰候选使排序 >10 升至 163～185 条并拉低 Hit@1/Hit@3，需在 V0.1.9 获准入后与排序模型联合验证。
  3. **`OBS-A-M2-01`（空池 `q_name[:4]` 兜底 vs M1 稀疏兜底）**：实测 `B0_KW_OFF` 中旧 `fallback` 命中 16 条目标槽位；切换 `M1_KW` 后其中 8 条（`GT-0091/0159/0172/0328/0621/1029/1136/1146`）由稀疏通道承接且多数排名提前，另 8 条（`GT-0074`～`0078` 医用铜制维修阀、`GT-1030` 发放窗、`GT-1100/1101` 接收窗）在 `limit=60` 下丢失。专项测试同时配对验证了长施工文本、设备位号+项目码、明确物理冲突（DN20 vs DN80）场景，硬约束在两条路径均生效。因此在默认全 OFF 下保留旧 `fallback` 路径、不强行移除，并将配对事实留档。
  4. **`OBS-COORD-M2-01` 与 `OBS-A-M1-01`**：无并行负载同条件重测下 `B0_VEC_OFF` 回到 `60.5 / 287.0 ms`（低于 90/375 ms 上限），确认 M2 轮偏差源于当轮并发/宿主负载；`_fts_raw_rows` 收敛至 512 后 `M0M1_KW` 峰值由 780.37 降至 770.61 MiB，仍超 768 MiB 上限 2.61 MiB，维持禁用。
