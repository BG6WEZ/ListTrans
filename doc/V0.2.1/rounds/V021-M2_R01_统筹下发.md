## 范围与验收

严格按 R2 方案第四节第 4～7 项与第五节 M2 行实施：

| 条目 | 必做与验收 |
|---|---|
| 1. 优先核对（A 档）集中查看与逐行勾选资格 | 在工作台提供 A 档集中核对入口，**默认零勾选**，清晰区分“可逐行勾选”与“仅查看”。普通匹配 A 档须同时满足全部条件（前后端双重判定，服务端为最终权威）才允许逐行勾选：（1）实时编码有效且实时硬约束通过；（2）单位倍率确认为 1；（3）首选未封顶（`uncapped === true`）；（4）最终独立分差 ≥ 10 且有可靠非等价对手（`ranking_evidence_status == "current"`）；（5）当前绑定与首轮绑定一致（未改选/未重匹）；（6）当前处于待确认状态（未确认/未拒绝/未编辑失效）；（7）非适用安全关键未知；（8）非规则/BOM 来源（规则/BOM 跳过集中提交）；（9）**不存在清单明确要求而目录侧缺乏核验依据的参数（`requested_unverified == true`）**，例如 `GT-0300` 的功率 `40-50w` 转单行补证。目录未标注等**普通字段缺失**须在该行醒目展示字段名与缺失方（`清单缺失/目录缺失/均缺失`），展开清单原文与目录规格对照，由用户明确核对后逐行勾选。无符合勾选条件的行时展示明确原因并提供单行核对入口。 |
| 2. 已验证谱系按源行作用域隔离 | 已验证谱系的行（由服务端依据 `flywheel_documents/sheets/source_rows` 与登录态属主 `user_id + account_epoch` 校验）以 **`user_id + document_id + sheet_id + source_row_id`** 作为单行/批量确认、拒绝、失效、草稿恢复与导出的权威作用域，同步校验当前 `recommendation_revision`、行指纹 `row_fingerprint`、绑定指纹 `binding_fingerprint`、编码、数量和单位。现有按文件名与内容指纹的凭据（`make_scope_key`）**仅限无已验证谱系的旧会话恢复使用**；已验证源行缺少源行作用域新凭据时返回待确认，严禁复用同单其他源行或同名重传的旧凭据。服务端须拒绝伪造、跨账号越权或省略已登记源行身份的请求；既有凭据无法证明对应单一源行时引导重新确认。须以**同单相同内容的两行**与**同名文件重传**实测验证独立确认、独立拒绝与独立失效。 |
| 3. 批量提交、幂等回执与跨库反馈投递 | 批量提交接口支持 `batch_request_id`（批请求标识）与行级 `idempotency_key`（绑定 `source_row_id` + 当前 `revision` + `binding_fingerprint`）。在 **`auth.db` 单一事务（`BEGIN IMMEDIATE`）** 内原子写入逐行权威决定（含源行作用域与权威单位证据）、逐行幂等回执与待投递反馈记录。提交前逐行重新核验目录实时编码、硬约束、单位倍率=1 与集中提交资格，支持部分成功并逐行返回成功或失败原因；并发编辑或状态漂移通过 `revision`/指纹冲突拒绝。部分成功后以同幂等键重试时返回已提交行原回执，并**核对提交后该行是否已被编辑/拒绝/失效**（绝不复活已失效确认）。`auth.db` 提交后将待投递反馈投递至 `materials.db`，按稳定事件 ID 幂等去重；`materials.db` 写入失败时保留 `auth.db` 已确认结果并保留待投递项支持后续重试直至成功。**集中确认事件标记独立来源，严禁写入旧无锁 `app/binding_feedback.json`**；验证旧规则建议（`/api/binding/suggestions` 等）计数不变，并验证飞轮挖掘（`feedback_miner.py`）与训练入口（`feedback_train.py` / `feedback_ranker.py`）对集中确认独立来源的隔离策略。 |
| 4. 导出校验、双库迁移与回退验收 | `/api/export` 与 `_gate_export_row` 对已验证源行按源行作用域核验权威凭据，沿用既有规则与实时编码/硬约束/权威单位证据校验；无有效凭据返回 422；行内容、单位或绑定编辑后立即失效（导出 422）；确认后导出 200 并重读 XLSX 逐格核对编码与数量。涉及 **`auth.db` 与 `materials.db` 两库的幂等迁移与保留列/表回退分别独立验收**；验证回退后旧读写路径正常，且已验证源行新版凭据若旧入口无法识别时按待确认处理。前端静态资源版本号同步递增为 `?v=v021_m2`，兼容深浅双主题。 |
