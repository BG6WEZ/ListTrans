## ENV-V017-01 · Linux 正式离线镜像

本机 Linux Docker `amd64` 实际以 `--pull=false --no-cache --network=none` 构建了隔离 scratch 镜像。读回全部 7 层，核对 73 份 RC 输入逐字节一致，两份精确校准 JSON 摘要一致，14 个合成排除探针均未进入构建产物。宿主专项验证校准文件缺失或摘要失配时失败闭合。[构建上下文与镜像层证据](../evidence/v021_preproduction_context.json) · [复验脚本](../evidence/v021_preproduction_context.py)

实际正式环境验收仍需确认目标机、Linux Python 3.11 基础镜像及匹配平台的带摘要依赖锁和完整 wheelhouse。本机 Docker 检查时未发现已导入的基础镜像，项目与已查本机路径未发现可用 wheelhouse。冻结 Dockerfile 的依赖安装命令引用外部仓库，正式断网构建需要在隔离构建目录以已验证的离线安装步骤替换该命令，并将构建定义和产物绑定到签认源码。验收须检查正式镜像全部层、关键词与 BGE 双模式断网脱敏启动，以及镜像内两份校准 JSON 的摘要和篡改降级。[Linux 门禁原文](../../V0.1.7/03_终审与版本准入.md)
