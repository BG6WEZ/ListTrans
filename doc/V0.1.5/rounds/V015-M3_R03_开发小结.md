## 本轮完成

严格按 R02 统筹裁决仅整改剩余 3 项阻断（`A-M3-01` P1、`A-M3-02` P1、`A-M3-05` P2），保持已关闭项 `A-M3-03`/`A-M3-04` 及 `M0～M2` 既有契约不变，未改动权重与模型，未触及暂挂 `R-M3-01`（P2）：

1. **`A-M3-01`（P1）空目标单位确认与确认后单位漂移/残缺历史记录导出闭环**
   - [app/binding_decisions.py](../../../app/binding_decisions.py)：
     - `evaluate_hard_conflicts` 在 `allow_unit_conversion=True` 且 `abs(mult - 1.0) > 1e-9` 时，拒绝空/缺失目标单位 `b_unit`；
     - 新增 `_enrich_saved_bindings` 并在 `record_decision` 中持久化实时 `confirmed_unit`、`confirmed_orig_unit`、`confirmed_orig_qty`、`confirmed_unit_mult` 证据；
     - `validate_bindings_against_row(..., require_saved_unit_evidence=False)` 启用强证据校验时，拦截历史空目标单位确认记录、实时 `unit` 漂移、`confirmed_unit_mult` 漂移及客户端篡改/增删 `unit`。
   - [app/server.py](../../../app/server.py)：
     - `_annotate_restored_items` 与 `_gate_export_row` 传入 `require_saved_unit_evidence=True`：会话恢复发现单位证据缺失或漂移时自动降级并附带冲突原因；
     - `/api/export` 的 `auto_accepted` 分支补充核验实时目标 `unit`，阻断空目标单位/比例漂移按原数导出。
2. **`A-M3-02`（P1）动态规则读取/解析失败必须 fail-closed 阻断**
   - [app/llm_rule_engine.py](../../../app/llm_rule_engine.py)：
     - 新增 `DynamicRuleUnavailableError(RuntimeError)` 与 `DynamicRuleInterpreter.validate_matching_rules`；
     - 加固 `LLMRuleManager.get_active_rules()`：仅当查询 `sqlite_master` 确证 `llm_rules` 表不存在时返回 `[]`；遇到 SQL/列缺失/连接异常或非法 `rule_json`/`matching_rules` 时不写 `_active_rules_cache`，直接抛出 `DynamicRuleUnavailableError`。
   - [app/matcher.py](../../../app/matcher.py)：
     - 定义 `DYNAMIC_RULE_UNAVAILABLE_PREFIX`，使 `evaluate_dynamic_exclusions` 返回不可用阻断原因（不再返回空列表 `[]`）；
     - `_apply_dynamic_rules` 在规则不可用时 fail-closed（`ctx.blocked = True`、`ctx.max_score = 0.0`、`base_score = 0.0`）。
   - [app/binding_decisions.py](../../../app/binding_decisions.py)：
     - `evaluate_hard_conflicts` 区分并分别阻断 `"动态规则不可用阻断: ..."` 与 `"动态规则硬排除: ..."`，覆盖推荐、批量匹配、确认、恢复与导出全链路。
3. **`A-M3-05`（P2）移除硬编码 `"给排水"` / `"通用"` 专业泄漏，单源收口**
   - [app/normalizer.py](../../../app/normalizer.py)：作为无循环依赖单源（SSOT）承载 `PROFESSIONAL_ALIASES`、`DYNAMIC_UNIVERSAL_TOKENS`、`normalize_professional_category`、`dynamic_scope_matches`、`dynamic_rule_matches_query`、`_cleaning_rule_in_scope` 与 `_apply_dynamic_cleaning_pass`。
   - [app/matcher.py](../../../app/matcher.py)：从 `app.normalizer` 导入并重导出 `PROFESSIONAL_ALIASES`、`normalize_professional_category`、`dynamic_scope_matches as _dyn_scope_matches`、`dynamic_rule_matches_query as _dyn_rule_matches_query`，删除本地重复定义与硬编码 `"给排水"`/`"通用"`。
   - [app/query_preprocessor.py](../../../app/query_preprocessor.py)：步骤 1 向 `clean_text_standard` 透传 `discipline=cat_clean, category=cat_clean`；步骤 8 改用 `app.normalizer.dynamic_rule_matches_query`，移除内联硬编码 `["给排水", "通用"]`。
4. **R03 回归与端到端实测新增（+8 项，全量 233 → 241）**
   - [tests/test_m3_hard_constraints.py](../../../tests/test_m3_hard_constraints.py) 新增 `TestM3R03AuditClosureUnit`（5 项纯函数与引擎单测，覆盖 `A-M3-01`、`A-M3-02`、`A-M3-05`）。
   - [tests/test_m3_hard_constraints_http.py](../../../tests/test_m3_hard_constraints_http.py) 新增 `TestM3R03AuditClosureHttp`（3 项真实 Flask/SQLite/`openpyxl` HTTP 端到端测试：空目标单位确认 `409` / 确认后漂移与客户端篡改与历史 DB 空单位恢复降级及导出 `422`；`llm_rules` 损表导致 `/api/match`、`/api/batch_match`、`/api/binding/submit`、`/api/session/annotate`、`/api/export` 全链路阻断与修表恢复；`给排水` vs `暖通` 与 `"通用"` 专业规则严格隔离）。
