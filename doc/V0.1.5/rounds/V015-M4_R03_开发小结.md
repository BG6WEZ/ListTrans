   - 因人事 Excel 同步表不含启用/停用状态列，常规全量/增量同步时：
     - 已被管理员停用（`is_active = 0`）的账号在**角色未变**（如 `employee -> employee`）与**角色变化**（如 `manager -> employee`）场景下均严格保留 `is_active = 0`（登录继续 `403`、并发旧 Token 继续 `401`）；

     - 未停用且角色未变的既有账号保持 `is_active = 1` 与原 `token_version`（正常会话继续 `200`）；中途中止异常继续触发事务完整回滚。
     - 停用账号的重新启用仅允许通过经管理员鉴权的显式接口 `PUT /api/admin/users/{user_id}`（`{"is_active": true}`：`admin` 返回 `200` 并递增 `token_version`，非管理员 `employee` 返回 `403`）。
