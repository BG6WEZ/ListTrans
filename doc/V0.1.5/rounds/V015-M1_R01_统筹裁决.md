### 锁定的保护契约

1. 原有Top1掉出和排名净退化检查保留；逐例新增保护，不用其他样本的改善抵消单例违反新增保护。
2. 对基线已正确Top1的可比样本，令`G`为该例金标目标编码集合，`s`为候选原始合分；`T=max(score(code) for code in G)`，`W=max(score(code) for code not in G)`，存在非目标候选时`margin=T-W`。同一例候选配置的`T`和可比`margin`均不得下降；下降即拒绝。候选结果中正确目标丢失继续按现有排名门禁拒绝；基线无非目标候选、候选新增非目标候选等无法直接比较margin的情况须保守拒绝或交人工复核，不能静默算无退化。
3. 比较使用有限、未展示舍入的原始数值，仅允许固定绝对浮点误差`1e-6`；不能从GT-0313的差值反推业务阈值，不能把GT编号、关键词、电缆编码或本次分值写成规则。此为保守零退化保护，不是自动接受置信度校准；可能增加人工复核，须在正向/中性对照中明确报告影响。
4. 输出须能追溯每例目标码、可比得分/间隔和拒绝原因，不得只依赖截断的top5、两位展示分数或汇总计数。输入条件不完整（样本ID不一致/重复、非有限数值、缺必需字段、子进程非零退出/逐例异常）不得`passed=true`。空集或没有可验证的正确基线仍不能用“全0稳态”证明通过。
5. 基线/候选必须同物料快照、金标、模型/向量通道及预算，只有拟评测规则不同；记录必要快照哈希与通道标识。同进程无向量探针不能替代实际双子进程链路。不得改matcher权重、召回/排序算法、规范化语义或自动接受阈值来迁就测试。
