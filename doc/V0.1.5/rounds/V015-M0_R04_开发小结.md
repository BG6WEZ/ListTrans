| 诊断项 | 实测 |
|---|---|
| 定向样本数 | 金标按 `--filter-keyword 排风机` 口径命中 25 条（样本 GT-0217 空调自控系统 / GT-0313 排风机控制盒 / GT-0576 电力电缆头 / GT-0664～0668 医用静音型排风机）；沙箱 report targeted_count=24（工具六字段口径微差） |
| 规则是否实际生效 | 生效：沙箱机制正常，有害别名规则已注入 candidate 的 alias_dict.json（注入链路无缺陷） |
| 基线/候选逐例排名变化 | improved=0、degraded=0、degraded_from_top1=0，details 空 |
| 门禁实测 | `passed=true`，reason="门禁通过：稳态无退化（改善: 0 条, 恶化: 0 条）" |
| 机制根因 | 隔离空物料库 `materials_rows_after_init_db=0`、`materials_matching_target_prefix=0` → eval_golden_set 的 rank 语义为目标码不在候选时记 0 → 基线与候选 rank 恒 0、逐例无变化 → 门禁按"稳态无退化"放行，规则效果不可观测 |

| DB/配置/金标/模型标识 | 隔离根 `listtrans_legacy01_*`（临时目录）；金标 `tests/fixtures/golden_set_v1.json`；离线模型 `model_offline/bge-small-zh-v1.5`（dim=512），vector_index_enabled=true；无网络下载、无付费调用 |

**结论**：断言失败根因为**测试前置条件缺失**——隔离空物料库使金标目标物料无候选，排名恒稳态，有害规则与任何规则效果均不可观测；属"缺测试数据"类。修复需覆盖 24 条金标目标物料的业务库级数据源或评测链路调整，超出 R04"隔离 fixture 补合成前置数据"授权（合成几条物料无法代表真实召回排名分布，且裁决禁止改门禁/算法/生产评测链路），**回交统筹裁决**。本轮未删断言、未 xfail、未标记跳过、未改金标。
