## 4. C-M0-08 闭合核验（双入口不可变事件、同事件重试、停试、刷新保留与隔离）

裁决第四节 4 条要求与第五节门禁逐条核验。源码复核依据 `diff_appjs.txt`（36442 B）、`diff_test_v016.txt`（29112 B）、`diff_server.txt`。

### 4.1 前端事件生命周期（web/app.js）

- 不可变事件：两入口 `reportFlywheelAction`/`submitFeedbackSample` 均先 `ensureVerifiedActorIdentity()`，一次性分配 `client_event_id` 与递增 `event_seq`，`Object.freeze(payload)` 后深克隆入 record；重试不新建 UUID、不增 seq。
- 有界同事件重试：`_getRetryPolicy()` 默认 `{maxAutoRetries:1, retryDelayMs:120}`；`_dispatchSingleFeedbackRecord` 循环内仅对 `status===0 || >=500 || 429 || 408`（含 catch 网络错落 status=0/network_error）重试；409 落 `blocked_conflict`、422/404/400/403 落 `blocked_invalid` 立即停试，不进重试队列；横幅文案明示「409/422 已停止自动重试」，手动按钮 `#retry-pending-feedback-btn` 只重放 pending/failed_retryable 且按 seq 排序。
- 刷新保留：localStorage key `listtrans_pending_feedback_v1` 仅持久化非 delivered 事件；`reconcilePendingFeedbackForDocument` 用待投递 seq 抬高行级 `_event_seq/_feedback_seq` 下界，恢复后新动作不冲撞旧序号。
- 主体与文档隔离：record 绑定 `(actor_user_id, actor_account_epoch, document_id, sheet_id, source_row_id)`；`_actorMatchesRecord` 三重判定；`purgePendingEventsExcept`（切账号）、`purgePendingEventsForDocument`（切文档/结束任务）；Bob 携 Alice storage 登录即被 purge。
- 迟到重试：服务端回 `is_stale_arrival=true` 并将旧事件置 superseded，不覆盖更新状态；确认状态与反馈投递状态分区展示，反馈失败不伪造确认/导出资格。
- 服务端改动最小：app/server.py 仅 3 字段增补（diff_server.txt），R02 全部 M0 保护哈希维持。

### 4.2 Node-IPC 直连真库三新用例（专项 15 项内，审核机 15/15 通过）

测试架以 Node `vm` 注入真 `web/app.js`（假 fetch/localStorage/document/window），FETCH/DONE/ERROR NDJSON 行协议转发到 Python 侧真 FastAPI TestClient + 真 SQLite，故障注入点全部显式标注：

1. `test_r03_cm008_frontend_retry_same_event_and_json_self_heal`：提交前断网同 body 两次仅 1 DB 行；提交后丢回包第二次 `idempotent_replay=true`；`patch sync_trusted_feedback_file side_effect=OSError` 造真 500 两次，横幅/按钮断言成立，手动重试 200 replay，三次请求 body 全等，SQLite 与 JSON 文件各 1 事件且 JSON 自愈。
2. `test_r03_cm008_non_retryable_409_422_dual_actions_and_late_retry`：预置 seq=1 造真 409、伪造 source_row_id 造真 422，各仅 1 请求且不进重试队列，`decision_status='manual_confirmed'` 不被改写；双动作 UUID 不同、seq=1/2；迟到重试回 `is_stale_arrival=true`，DB 断言 `[(1, superseded=1, stale=1), (2, 0, 0)]`。
3. `test_r03_cm008_pending_persistence_reload_and_cross_account_isolation`：Alice 503 失败后 localStorage 留存，同文档 annotate 恢复后 pending 可见且重试成功；切文档零泄漏；Bob 携 Alice storage 登录被 purge，`bob_dispatched == []`。

### 4.3 Chrome 真实 DOM 验收（裁决第五节：Node 不能替代浏览器）
