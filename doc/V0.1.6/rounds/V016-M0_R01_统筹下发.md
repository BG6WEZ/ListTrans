## 二、本包目标和允许范围

对应 **F05 / P1：反馈身份与事件契约**。让同一操作的重试只记一次，让不同用户、文件、工作表的同一行号互不覆盖；能查清初始推荐、用户最终选择和实际运行版本。

允许按依赖最小范围修改：`app/server.py` 的上传/任务结果、重算及反馈接口，`app/flywheel_db.py` 的反馈存储/迁移，`app/session_manager.py` 的身份保存恢复，`app/feedback_train.py` 的旧反馈入口适配，`web/app.js` 的身份传递与事件发送，以及必要的独立身份/契约模块、测试和本包文档。实施前列明实际文件清单并备份本包起点，新增模块说明依赖及导入副作用。`web/index.html` 仅在真实交互必要时最小调整。

`/api/flywheel/record` 与 `/api/feedback/submit` 均须调查和处理，不能留下另一条无身份写入旁路。上传、单行/批量重算和草稿/命名会话恢复如需传递上下文，可做本包必要贯通；不扩做 UI 改版、挖掘策略或算法优化。底层认证代码原则上保持，仅复用 M4 已验证身份契约；若确需改变其契约，先报统筹裁决。

不下发 F06/F27 挖掘治理、F07/F28 完整发布门禁、F08 运行评测资产或 F20 阶段诊断；这些仍归 M1～M4。旧读者必要兼容和可信数据入口过滤可做，须说明与 M1 的接口。TMP-MAT-SYNC 保持方案研究，禁止借本包实施同步、连接源库或建立定时任务。

## 三、必须实现的契约

| 编号 | 约束与验收口径 |
|---|---|
| C01 身份来源 | 写入用户身份必须来自服务端验证后的认证主体，使用不可变 `user_id`；复用既有账号 epoch 防删除重建串权，不以 username、客户端 user_id 或 anonymous 代替。未认证 401；跨用户/失效 epoch 沿用既有不泄露资源存在性的拒绝策略。 |
| C02 对象身份 | 区分业务上传/文档任务、工作会话和保存进度 ID；具有稳定 task/document、sheet、source_row 标识并保留原始工作表/物理行坐标。相同文件名、相同内容再次上传须生成独立业务文档。排序、编辑、重算、刷新、保存和恢复不能用当前 UI 序号重建源行身份。 |
| C03 归属校验 | 服务端签发或验证文档→工作表→源行关系及所有权；缺失、伪造、错配身份返回明确 400/422，跨账号访问拒绝，且无反馈/替代状态副作用。不得退回 `default_session`。不能仅凭客户端自报一组 UUID 就认定归属。 |
| C04 初始与最终 | 首次实际推荐快照与最终人工动作/目标分别持久化；编辑、重算、改绑不得反写初始推荐。需要更新的后续机器推荐作为独立 revision 记录。反馈不代替 M2 的确认凭据，不能借提交反馈获得可导出/已确认状态。 |
| C05 真实上下文 | 接入主链路 `professional`、`parsed_spec`，原始输入与必要变更可追溯。算法/模型/配置标识来自实际执行的服务端版本/内容摘要，绑定该次推荐快照；禁止用固定 `v1.0`/`snap_v1` 冒充真实版本，禁止直接信任客户端上报的初始推荐和版本。确实不可用时明确标记，不伪造。 |
| C06 幂等与替代 | 每次业务动作生成事件 ID，网络重试沿用该 ID；相同事件同内容返回同一结果，不重复插入/计数/置过期。同键不同内容或不同对象须冲突拒绝（409）。插入与 superseded 更新同事务，只能影响同一认证主体、业务文档、表、源行；不得跨对象置过期。 |
| C07 乱序与并发 | 规定同一对象的事件 revision/顺序契约：迟到的旧请求不能覆盖已生效的新最终状态；冲突拒绝或确定性单调接纳均可，但不能仅按到达数据库的先后伪称用户最终顺序。保留事件历史和有效最终视图，失败完整回滚，可安全重试。 |
| C08 恢复与遗留 | 新身份经保存/草稿/命名恢复和服务重启保持稳定且复核 owner/epoch。旧 `default_session`、缺身份或无法证明来源的记录保留并标记 legacy/untrusted，不推断补造真实归属，也不进入本版可信新增反馈。旧草稿无可核验来源时明确提示/隔离；需要重新上传或产生新事件时须标记新采集边界，不能把旧客户端内容升格为原始服务端快照。 |
| C09 兼容与迁移 | 提供契约/schema 版本、旧调用处理与重试说明；新旧数据兼容、迁移可重复执行、失败无部分写入。只在空库或合成/脱敏隔离副本演练；实际业务库保持冻结。回滚说明必须保护已写入的新身份和历史，不允许直接删库回退。 |

接口字段名称可以按现有代码合理确定，但开发小结必须给出字段映射、可信来源、事件唯一键、替代键、乱序策略及旧入口兼容表，独立审核按实际 HTTP 与落库语义复验。
