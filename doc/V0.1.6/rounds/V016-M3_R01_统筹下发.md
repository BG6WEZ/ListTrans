## 四、最低验收矩阵

1. **无 `tests/`/`doc/` 运行独立性**：构建干净运行时上下文（或容器/独立临时复制目录，仅含 `Dockerfile` 允许打包的 `app/`、`web/`、`config/` 与脱敏运行资产，**不含 `tests/` 与 `doc/`**），验证三源沙箱评测（`manual_llm`/`legacy_binding`/`flywheel`）、门禁校验、`/api/llm-rules/stats` 与 `/api/export` 全链路可正常执行。
2. **Fail-Closed 资产缺失测试**：删除或损坏运行期黄金评测集/入口模块/物料资产，验证沙箱立即返回 `failed` / `safety_passed=False` / `benefit="invalid"`，发布门禁拒绝放行，且不回退读取宿主 `tests/` 或放行空集。
3. **模型可用 vs 降级路径**：分别验证挂载离线 `bge-small-zh-v1.5`（混合召回正常、`vector_channel.enabled=True`）与无模型路径（状态如实记录、不伪造启用、门禁与降级行为确定）。
4. **静态路由优先回归**：覆盖 `/api/llm-rules/stats` 在无数据、有规则数据及存在 `rule_id="stats"` 时均命中共用统计处理器，且受权限控制保护。
5. **容器镜像构建与层安全审计**：核查 Docker daemon 状态；可用时产出新镜像 ID、层文件清单与敏感文件扫描（0 敏感/业务库/人员表/`tests`/`doc` 泄漏）及上述容器内实测结果；不可用时明确标 `待验证`。
6. **既往护栏持续回归**：主机隔离全量 pytest（>=353 项，无删断言/降门槛）、三规则门禁对 `m0_r03`/`m3_r04`/`m4_r03`/`m5_r04`/`m2_r01` 零分差、GT-0674/0677/0678 维持 `recommended`、M0/M1/M2 核心保护持续通过。
