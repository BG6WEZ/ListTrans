## 六、 常见问题与应急排障方案

### 6.1 访问门户或某个服务超时 / 打不开
1. **排查容器存活状态**：
   ```bash
   docker ps -a
   ```
   检查是否有容器处于 `Exited` 状态。如异常退出，使用 `docker logs <容器名>` 查阅崩溃堆栈。
2. **排查端口监听状态**：
   ```bash
   ss -tulpn | grep <端口号>
   ```
3. **排查防火墙是否拦截**：
   ```bash
   firewall-cmd --list-ports
   ```

### 6.2 磁盘空间报警（根目录或 /home）
1. 运行 `df -hT` 快速确认是哪个分区占用过高。
2. 若 `/home` 膨胀过快，重点检查：
   * 视频监控录像切片：`/home/huakang/wvp-GB28181-pro/record`（检查定时任务 `record_cleaner.py` 是否正常调度）。
   * Docker 无用镜像与悬挂数据：
     ```bash
     docker system df
     docker image prune -a --filter "until=168h"   # 清理1周以上未使用的旧镜像
     ```

### 6.3 服务器重启后自愈规则
* 所有核心业务容器均已设置 `restart: always` 或 `restart: unless-stopped`，在宿主机断电重启后，`docker.service` 随操作系统自启后会自动恢复全部 9 个业务容器。
* Cron 任务位于 `/etc/cron.d/wvp_record_cleaner`，系统启动后 `crond` 会自动加载执行。
