## 二、本包调查起点（只读源码事实与 F23/F24/工程依赖）

1. **同步阻塞主事件循环（`F23` 第一阶段）**：
   - `app/server.py` 存在 4 线程全局 `executor = ThreadPoolExecutor(max_workers=4)`（L1601），但仍有 `async def` 路由直接执行同步文件 I/O、Excel 生成/导出（如 `export_report` L4044）、规则挖掘/同步网络请求或重型 DB/序列化操作，高并发或大文件场景会阻塞 FastAPI 主事件循环。
2. **后台任务队列无界积压、取消与超时清理不足（`F24` 完整治理）**：
   - 上传匹配（`upload_file` L2052）、物料库导入（L4580 `_DB_IMPORT_TASK_TIMEOUT_SECONDS = 600.0`）、全量重解析（`api_db_reparse` L4969）、规则挖掘与沙箱评测等后台任务缺少统一的并发/排队限额、显式取消信号、超时回收与过期任务态内存清理机制，异常或慢任务易导致队列无限积压或状态表泄漏。
3. **日志、上传与导出产物缺少受控保留/清理策略**：
   - `app/uploads/`、`output/`、导出临时文件与运行日志缺少带保留窗口（TTL/数量上限）与授权边界的受控清理机制；清理逻辑严禁误删受保护业务数据、备份或正在进行的任务文件。
4. **工程依赖与离线资产清单未统一锁定，缺少负载下的队列/P95/内存实测**：
   - `requirements.txt`、`requirements-test.txt` 与离线模型/wheel/配置资产需核对并锁定经验证版本清单，同时在受控隔离负载下实测队列等待、主服务响应性、单条/批量 P50/P95 与峰值内存，为统筹在 V0.1.7 终审锁定 `V0.1.8/V0.1.9` 候选预算与时延门槛提供无后台负载独立基线。

## 四、最低验收矩阵（开发自验与独立审核必查）

1. **主循环响应性实测**：隔离服务并发运行重型导出/匹配/挖掘任务时，并发请求轻量端点（如健康检查/状态接口）均在阈值内正常返回，无事件循环阻塞超时。
2. **队列限额、取消与超时回归**：新增专项单测覆盖超限拒绝、任务取消协作退出、超时清理与锁释放、异常不积压、历史终态任务 LRU/TTL 淘汰。
3. **保留与清理安全边界**：专项单测验证仅清理过期临时上传/导出/日志，不误删活跃任务文件、不越界跳出允许根目录、无管理员权限调用清理接口返回 403、dry-run 不删文件。
4. **依赖与离线资产清单**：`requirements` 与离线模型/资产清单哈希可复核、无未声明隐藏依赖、无外部连网需求。
5. **无后台负载性能与指标基线**：双模式 P50/P95/峰值内存、队列等待与 1,220 条三口径指标完整落盘（附机器规格、采样数与 `OBS-M2-01` `Hit@3` 核对）。
6. **全量 pytest、三规则门禁、隔离与交付哈希**：Windows 双隔离根全量 pytest（`>=405` + M3 新增）全通过、`EXIT=0` 并落盘日志；三规则门禁 18 组 `score_diff_count=0`、`EXIT=0`；`verify_isolation.py` 前后 PASS；外层 35 项业务资产与冻结夹具 0 字节变化；落盘 `doc/V0.1.7/rounds/V017-M3_R01_开发小结.md` 与 `doc/V0.1.7/evidence/m3_r01_delivery_hashes.md`（最后一次测试修改后重新计算全部改动/新增文件 SHA256）。
