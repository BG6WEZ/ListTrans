## 四、最低验收矩阵（开发自验与独立审核必查）

1. **快照与对账真实性**：实测回算 `materials.db`、`golden_set_v1.json`、停用审计 CSV、`doc/物料库` 与 `ground_truth_500.json`，每一项总数、不在库数、专业分布、同名同规格组数均有可复现脚本、输入快照 SHA256 与机器可读报告，可被审核机独立重算一致。
2. **五分类全覆盖与防篡改**：全部不在库样本 100% 落入五分类，每类均有条数统计与代表性反例/正例证据；`pending_business_review` 明确单列不悄悄删样；确认 `tests/fixtures/golden_set_v1.json`、`golden_baseline.json`、`app/eval_assets/*` 及 `app/materials.db` 哈希 0 变化。
3. **重复组等价映射严谨性**：同名同规格重复组能清晰区分“因品牌/单位/描述不同应保持区分的正例（不得合并）”与“实质等价编码组”，并有单元/集成测试证明含等价组判定不会把不同品牌/单位误作等价。
4. **防泄漏划分与多口径对比可信**：`train / dev / test` 按项目/工作表/相似组隔离，交叉验证无同工程/同签名泄漏（若有仅 2 个项目导致的物理切分说明，必须实事求是记录按 sheet/群组隔离粒度与剩余相关性风险，不伪造完美无相关）；三套口径报告与基线差异解释清晰、无拿旧 96% 凑数。
5. **`指标目标与性能预算.md` 证据实测完整**：必须真实启用离线 `bge-small-zh-v1.5` 跑完隔离黄金集全量与批量匹配性能测量（P50/P95/峰值内存、分域分指标表、硬件配置），不手工估算或补造数字；若 `V0.1.7` 后续待 M1～M3 完成后正式签认最终门槛，须在文档中明确标注“M0 实测当前基准与候选预算目标，待统筹核验签认”。
6. **既有护栏与 `OBS-AUDIT-M4-01` 回归**：`OBS-AUDIT-M4-01` 空 `src` 守卫与导出回归测试通过；既有三规则 6 基线零分差、`GT-0674/0677/0678` 维持 `recommended`、Windows 双隔离根全量 pytest（>=373 项 + M0 新增）全通过、前后 `verify_isolation.py` PASS 及外层 35 项业务资产快照零变化。
