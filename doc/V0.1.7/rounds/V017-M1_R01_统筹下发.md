## 二、本包调查起点（只读源码事实与问题清单）

1. **扁平属性结构与非白名单噪声渗入**：
   - `app/query_preprocessor.py`（`extract_query_params`、`parse_query_kv_blocks`）与 `app/preprocessor.py`（`extract_params`、`extract_general_params`、`parse_sub_parameters`）输出的 `attrs` 仅存扁平标量或零散 `_min/_max/_op/_base` 后缀键，缺少统一类型化元信息（`value`、`unit`、`operator`、`source`、`source_span`、`confidence`、`status`）。
   - `app/preprocessor.py:257-261`（`parse_sub_parameters`）会将无冒号短句直接写入 `sub_params[part] = part`，且冒号键值对未做领域/属性白名单过滤；施工描述、安装要求或非属性短句易混入 `attrs` 并直接进入 `app/matcher.py:865` 的 `processed_keys` 参与属性打分。
2. **DN 与 De/Φ 混淆未根除**：
   - `config/domain_schema.json` 中 `chiller`（`:368`）、`valve_water`（`:811`）、`valve_medical_gas`（`:912`）、`pipe_steel`（`:967`）、`pipe_ss`（`:1023`）、`pipe_plastic`（`:1086`）的 `管径` 正则仍把 `DN|de|De|Ф|Φ` 混在同一捕获组；
   - `app/domain_extractors.py:228-231` 与 `:479-485` 调用 `convert_de_to_dn()` 将 `De` 暗转为 `管径` / `dn_val`；
   - `app/preprocessor.py:49-50` `DEFAULT_UNITS` 与 `config/unit_rules.json:12-13` 存在 `"Ф": "DN", "Φ": "DN"` 映射（需注意：工作区 `config/` 属于外层 35 项受保护快照，不得直接覆盖改写工作区文件，应在代码规范化层或兼容运行逻辑中消除误映射并保持只读隔离）。
3. **产品型号与工程设备位号/箱号混同**：
   - `app/preprocessor.py:100-135` `extract_model()` 会将 `AP-1`、`AL-2`、`AHU-J-01`、`PAU-D301` 等工程设备位号或配电箱编号当作产品 `model` 提取，进入 `matcher.py` 后易干扰 `scene_a` 与 `model_conflict` 判定。
4. **材质牌号冲突分支尚有残留**：
   - `app/matcher.py:1060` 材质回退分支仍有 `["不锈钢", "304", "316l", "不锈钢304"]` 列表判断，与 `KNOWN_MATERIAL_GRADES`（304 vs 316L 严格区分、泛称“不锈钢”维持 unknown 宽容）语义存在局部不一致风险。
5. **结构化质量统计指标失真**：
   - `app/db_manager.py:1460-1532` `get_db_schema_stats()` 第 1510 行对无 `must` 字段的 `generic` 等域直接记 `must_fill_rate = 1.0`，虚高总体填充率（2026-11-12 审计记录为 60.66%），且完全缺失独立于填充率的“路由正确率”与“字段抽取正确率”统计。

## 三、必须实现的契约（M1-C01～C06）

| 编号 | 契约名称 | 必须满足 |
|---|---|---|
| M1-C01 | 统一类型化字段结构与字段白名单 | 为 Query（`extract_query_params` / `prepare_query`）与 Material（`extract_params`）统一提供结构化类型化属性字典 `typed_attrs`（每个字段包含 `value`、`unit`、`operator`、`min_val`/`max_val`、`source`、`source_span`、`confidence`、`status`，其中 `status` 区分 `known` / `negated` / `unknown`），同时保持顶层 `attrs` 向后兼容；建立受控的领域与通用属性字段白名单，将 `extract_general_params` / `parse_query_kv_blocks` 中未命中白名单的自由文本键隔离至 `unwhitelisted_attrs`（仅供展示/追溯），严禁非白名单噪声键进入 `attrs` 参与 `app/matcher.py` 属性打分。 |
| M1-C02 | `F26` 完整治理：范围/不等式/DN/De/尺寸/材质牌号/位号规范与三态一致性 | 1. **DN 与 De/Φ/外径彻底分离**：清理抽取与配置正则中把 `Φ`/`De` 直接改写或暗转为 `DN` 的逻辑（保留 `conduit` 领域 `SC`/`RC` 标准对照的显式 `公称直径DN` 与 `外径mm`）；<br>2. **范围/不等式/公差与数值类型统一**：规范范围（`~`/`-`/`至`）、不等式（`≥`/`≤`/`>`/`<`）、约数、`±` 三维公差框及数值类型归一，消除 `15` vs `15.0` 等同值不同格式比较误扣分；<br>3. **材质牌号与否定三态一致性**：消除 `app/matcher.py:1060` 残留泛化列表，使 `304` vs `316L` 在属性分与硬约束中一致判冲突、泛称“不锈钢”与具体牌号保持 `unknown` 宽容；`unknown` 绝不冒充 `False`（否定仅在显式否定词命中时成立）；<br>4. **产品型号与项目设备位号分离**：区分真实产品型号（`model`）与项目设备位号/箱号（如 `AP-1`、`AL-1`、`AHU-J-01`、`PAU-D301` 等归入 `tag_id` / `box_type` / `unit_code`），避免位号差异误触发型号冲突。 |

## 四、最低验收矩阵（开发自验与独立审核必查）

1. **类型化字段与白名单防噪**：Query 与 Material 均产出合规 `typed_attrs`（`value/unit/operator/source/confidence/status`）；施工说明、无冒号冗余短句及非属性自由键值均被拦截在 `unwhitelisted_attrs` 外，不进入 `matcher.py` `processed_keys`。
2. **`F26` 全分支回归**：覆盖 `DN` vs `De/Φ` 不混同、`15` vs `15.0` 等值、`304` vs `316L` vs 泛称“不锈钢”、否定三态（`非`/`不带`/`unknown` 不冒充 `False`）、范围/不等式/`±` 三维公差、真实型号 vs 设备位号/箱号（`AP-1`/`AL-2`/`AHU-J-01`）。
3. **版本化重解析（`schema_version = 3`）与兼容性**：隔离副本 26,863 行重解析全量升级至 `v3` 并可回滚；旧版 `v0/v1/v2` 缓存物料行在未重解析场景下仍可被 `matcher.py` 安全读取且不报错。
4. **统计去虚高与小样本实测**：`get_db_schema_stats()` 明确分离 `has_must` 与 `generic/no_must`，`generic` 不再以 100% 抬高总体填充率；`structured_extraction_eval_v1.json`（`>=60` 条，0 条来自 `test` 集）实测路由正确率、字段 Precision/Recall/F1 完整落盘，歧义样本逐条留痕。
5. **M0 基准回归与门禁对比**：离线 `bge-small-zh-v1.5` 与 `keyword` 双模式三口径指标（含 `train/dev/test` 分片，仅作只读基准对照、不调参）对比 M0 无退化；18 组门禁基准与 `GT-0674/0677/0678` 核验解释完整。
6. **全量 pytest、容器与隔离核验**：Windows 双隔离根全量 pytest（`>=377` + M1 新增）全通过、退出 0；`verify_isolation.py` 前后 PASS；外层 35 项业务资产与既有冻结夹具 0 字节变化；若修改 `app/` 运行模块并需要容器核验，保持复用/重建边界清晰并说明。
