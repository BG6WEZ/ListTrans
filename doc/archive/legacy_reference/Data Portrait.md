### 1.3.3 四类典型文本结构
1. **纯 K:V 链条**：`风量：3140m³/h，机外余压650pa，镀锌钢板` — 低难度
2. **纯尺寸+材质隐式**：`1550*450*2000，镀锌钢板，阻性` — 中，需正则形态判定
3. **型号代号+复合乘式**：`WDZ-BYJ 4*6+1*4` — 高，需处理 `+` 拼接
4. **单位嵌入 Key 名**：`电加热功率KW:2` — 中，Key 需清洗

## 1.4 品类漂移现象（Class Drift）
样本证据：
- `调节阀` 分类下混录 `静压箱 1400*1200*1000 mm，PP`、`净化网孔板风口 550*400`
- `静压箱` 分类下混录 `中效过滤器`、`电加热器`、`多联式空调室内机`
- `冷热水机组` 分类下混录 `冷热源控制系统`、`控制面板`
- `蝶阀` 分类下混录 `PPH球阀 DN15，由令连接`
**结论**：不能仅依赖"物料分类"划定域，必须"分类 + 名称 + 规格正文"三源联合判定。
