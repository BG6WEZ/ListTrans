# 武汉华康世纪洁净科技股份有限公司 · 物料清单匹配系统技术方案说明书 (V0.1.2)

> **企业使命：以洁净技术赋能产业升级。**  
> **系统版本：V0.1.2 正式发布版**

本说明书详细阐述了武汉华康世纪物料清单匹配系统的设计与技术方案。该系统作为企业级通用的洁净工程清单数据处理平台，旨在通过结构化参数解析、多路召回（FTS5全文倒排+语义向量搜索+参数级组合召回）、双轨制打分、硬门控隔离规则与前端可视化校对，将项目设计原始清单（涵盖暖通、强电、弱电、给排水、医气等专业）精准匹配至企业的标准物料库，并无损输出为符合工程规范的标准报表。

### 1. 多路智能召回机制 (FTS5 + FAISS Vector + Parameter Recall)
为了兼顾“字面精确匹配”、“语义意图理解”以及“参数区间覆盖”，系统采用了三路召回架构：
* **FTS5 全文倒排索引召回**：利用 SQLite 内置的 FTS5 虚拟表，将特殊符号（如 `*`、`x`、`φ`、`DN`）进行符号解构，解决 SQLite FTS 语法冲突，秒级匹配字面相同的项。
* **FAISS 语义向量召回**：利用 `bge-small-zh-v1.5` / `SentenceTransformers` 对物料池进行向量化编码。使用 `faiss.IndexFlatIP` 内积索引库在毫秒级内检索出语义最接近的 Top 条目。
* **参数级多路组合召回 (V0.1.2 新增)**：针对离心风机箱、风机盘管等大品类候选，根据提取的属性（风量数值、外形尺寸、材质、防爆属性）进行多组合 FTS 检索，彻底解决大品类截断导致目标物料漏召回的问题。

### 2. 暖通与多专业特征抽取引擎
* **区间属性与比较器**：
  * 风量区间：`1~500m³/h`、`501~1000m³/h`（提取 `min`、`max` 数值区间）。
  * 余压区间：`≤500Pa`、`500Pa＜机外余压≤2000Pa`、`＞2000Pa`。
* **模式与结构推理**：
  * AHU 自取新风：检测 `送风量 == 新风量` 或 `自取新风` 标识，自动归类至 `净化循环机组（自取新风）`。
  * PAU 安装形式：区分 `吊装/吊顶`（优先匹配 `吊顶新风机组` 3.60.21.30xx）与 `落地`（优先匹配 `净化新风机组` 3.60.21.20xx）。
  * FCU 卡式与提升泵：自动识别 `卡式四吹` 与 `带冷凝水提升泵`。
  * 防火阀方圆截面：区分 `200*200` 矩形与 `φ300` 圆形截面，识别 70℃ 常开熔断 vs 电动执行器。

### 3. 双轨加权评分与 Hard Gates 引擎
* **第一轨：高精度型号精确匹配**：设备型号完全对准时，置为最高置信度。
* **第二轨：参数加权打分与区间容差**：
  * **区间容差豁免**：当风机风量（如 300）落入候选风量区间（1~500）时，豁免偏差处罚并加权 +0.40。
  * **缺省属性优选**：未标明防爆时优选非防爆并对防爆降权；未标明材质时优选镀锌钢板。
  * **跨形态与跨品类硬隔离**：
    * 风机盘管 vs 通风机箱双向硬隔离（`score ≤ 0.15`）；
    * 矩形截面 vs 圆形截面硬隔离；
    * 常开熔断阀 vs 电动控制阀硬隔离；
    * 管道/风管 vs 管件形态冲突惩罚（-0.40）。

### 4. 企业级安全与负荷监控体系 (V0.1.1)
* **服务器健康度与负荷警戒大盘 (Live Monitor)**：后台每 10 秒轮询系统 CPU、内存及磁盘占用。当系统总负荷达到 90% 警戒线时，自动捕获当前在线用户与正在执行的匹配任务快照并入库。
* **操作审计与日志链路**：全量捕获用户登录、登出、清单上传、导出、规则变更等操作流水，支持管理后台表格化查询。
* **会话与草稿物理隔离**：基于 `user_id` 在 `sessions.db` 中对草稿和暂存数据进行物理隔离。

## 五、 暖通专项匹配与改版物料库治理架构 (V0.1.2)

### 1. 改版物料库软删除隔离
针对 2026-08-17 改版物料库中的 10,281 条停用/无效数据，系统在底层 SQLite `materials` 表中引入 `status` 状态字段：
- `status = 1`：正常有效物料（参与 FTS 召回、向量检索与规则匹配）；
- `status = 0`：停用物料（物理保留以支持历史已绑定清单回显，但在任何新召回与推荐中自动过滤）。
